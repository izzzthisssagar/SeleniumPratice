findElement() vs findElements()

MethodReturnsIf Nothing FoundUse When
driver.findElement(By)Single WebElement (first match)Throws NoSuchElementExceptionYou expect exactly one element
driver.findElements(By)List<WebElement> (all matches)Returns empty List (no exception)Multiple elements possible (links, rows)
JavaFindElement.java
import org.openqa.selenium.By;
import org.openqa.selenium.WebElement;
import java.util.List;

// findElement — throws if not found
WebElement username = driver.findElement(By.name("username"));

// findElements — returns empty list if not found (safe)
List<WebElement> links = driver.findElements(By.tagName("a"));
System.out.println("Total links: " + links.size());

// Check if element exists without exception
boolean exists = !driver.findElements(By.id("submitBtn")).isEmpty();
System.out.println("Button exists: " + exists);

By Locators — Quick Overview

The By class tells Selenium HOW to find an element. Full deep-dive is Days 14–16. For today, these 4 are enough to write real scripts:

LocatorSyntaxFinds Element ByBest For
By.idBy.id("username")HTML id attributeMost reliable — IDs should be unique
By.nameBy.name("username")HTML name attributeForm fields (input, select)
By.xpathBy.xpath("//input[@name='username']")XML path expressionComplex elements, no id/name
By.cssSelectorBy.cssSelector(".oxd-input")CSS selectorClass-based, modern alternative to XPath
✅
OrangeHRM uses name attribute for login fields

The username field has name="username" and password has name="password". So By.name("username") is the cleanest locator for today. You'll learn all locator strategies on Day 14–16.

WebElement Core Methods

MethodWhat It DoesReturns
element.click()Click the element (buttons, links, checkboxes)void
element.sendKeys("text")Type text into an input fieldvoid
element.clear()Clear existing text from input fieldvoid
element.getText()Get visible text content of elementString
element.getAttribute("name")Get value of any HTML attributeString
element.isDisplayed()Is element visible on screen?boolean
element.isEnabled()Is element interactable (not disabled)?boolean
element.isSelected()Is checkbox/radio selected?boolean
element.getTagName()Get HTML tag name (input, button, div)String
element.getCssValue("color")Get computed CSS property valueString
JavaWebElementMethods.java
// Find an input field and interact with it
WebElement usernameField = driver.findElement(By.name("username"));

// Type into it
usernameField.sendKeys("Admin");

// Clear and retype
usernameField.clear();
usernameField.sendKeys("NewAdmin");

// Read back what's in the field
String value = usernameField.getAttribute("value"); // "NewAdmin"
System.out.println("Field value: " + value);

// State checks before interacting
System.out.println("Displayed: " + usernameField.isDisplayed()); // true
System.out.println("Enabled  : " + usernameField.isEnabled());   // true
System.out.println("Tag name : " + usernameField.getTagName());  // input

// Click a button
WebElement loginBtn = driver.findElement(By.cssSelector("button[type='submit']"));
loginBtn.click();

// Get text from an element
WebElement heading = driver.findElement(By.xpath("//h6[@class='oxd-text']"));
System.out.println("Heading: " + heading.getText());

First Full Script — OrangeHRM Login

This is it. Your first real end-to-end automated test. Read every line and understand what it does before running it.

JavaOrangeHRM_LoginTest.java — Line by line
package com.qaautomation.tests;

import com.qaautomation.utils.DriverFactory;
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import java.time.Duration;

public class OrangeHRM_LoginTest {

    private static final String BASE_URL  = "https://opensource-demo.orangehrmlive.com";
    private static final String USERNAME  = "Admin";
    private static final String PASSWORD  = "admin123";

    public static void main(String[] args) {

        WebDriver driver = DriverFactory.getDriver("chrome");

        try {
            // ── STEP 1: Navigate to login page ───────────────────
            driver.get(BASE_URL);
            System.out.println("[1] Navigated to: " + driver.getTitle());

            // ── STEP 2: Find & fill username field ───────────────
            WebElement usernameField = driver.findElement(By.name("username"));
            System.out.println("[2] Username field found: " + usernameField.isDisplayed());
            usernameField.clear();
            usernameField.sendKeys(USERNAME);
            System.out.println("[3] Entered username: " + usernameField.getAttribute("value"));

            // ── STEP 3: Find & fill password field ───────────────
            WebElement passwordField = driver.findElement(By.name("password"));
            passwordField.clear();
            passwordField.sendKeys(PASSWORD);
            System.out.println("[4] Password entered (length): "
                + passwordField.getAttribute("value").length());

            // ── STEP 4: Click Login button ────────────────────────
            WebElement loginBtn = driver.findElement(
                By.cssSelector("button[type='submit']")
            );
            System.out.println("[5] Login button enabled: " + loginBtn.isEnabled());
            loginBtn.click();
            System.out.println("[6] Clicked Login button");

            // ── STEP 5: Wait and verify dashboard loaded ──────────
            // Simple wait — Day 20 we replace this with proper explicit wait
            Thread.sleep(2000);

            String currentUrl = driver.getCurrentUrl();
            String title      = driver.getTitle();
            System.out.println("[7] Current URL  : " + currentUrl);
            System.out.println("[8] Current Title: " + title);

            // ── STEP 6: Assert login was successful ───────────────
            boolean urlPassed   = currentUrl.contains("dashboard");
            boolean titlePassed = title.equals("OrangeHRM");

            System.out.println("[9] URL has 'dashboard': "  + urlPassed);
            System.out.println("[10] Title is 'OrangeHRM': " + titlePassed);

            if (urlPassed && titlePassed) {
                System.out.println("\n✓ LOGIN TEST PASSED");
            } else {
                System.out.println("\n✗ LOGIN TEST FAILED");
            }

            // ── STEP 7: Verify dashboard element ─────────────────
            WebElement userDropdown = driver.findElement(
                By.cssSelector(".oxd-userdropdown-name")
            );
            System.out.println("[11] Logged in as: " + userDropdown.getText());

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } catch (Exception e) {
            System.out.println("✗ Test error: " + e.getMessage());
            e.printStackTrace();
        } finally {
            driver.quit();
            System.out.println("[QUIT] Browser closed");
        }
    }
}

Thread.sleep vs Proper Waits

🚨
Thread.sleep is a code smell — use it only temporarily

Thread.sleep(2000) always waits 2 full seconds, even if the page loaded in 200ms. This makes your test suite slow. On a slow network it may still not be enough — test becomes flaky. We use it TODAY only as a placeholder until you learn explicit waits on Day 20. After Day 20, remove all Thread.sleep calls from your scripts.

Wait TypeHow It WorksUse WhenStatus
Thread.sleep(ms)Hard pause — always waits the full time regardlessOnly as temp placeholder during learning❌ Remove after Day 20
Implicit WaitGlobal setting — waits up to X seconds for findElement()Set once in DriverFactory as safety net✅ Use now (Days 9–19)
Explicit Wait (WebDriverWait)Waits for a specific condition to be true, polls every 500msWaiting for specific element or state✅ Day 20 onwards — best practice

Complete Login + Logout Script

JavaOrangeHRM_LoginLogoutTest.java — Full script
package com.qaautomation.tests;

import com.qaautomation.utils.DriverFactory;
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;

public class OrangeHRM_LoginLogoutTest {

    static final String URL  = "https://opensource-demo.orangehrmlive.com";
    static final String USER = "Admin";
    static final String PASS = "admin123";

    static WebDriver driver;

    public static void main(String[] args) throws InterruptedException {
        driver = DriverFactory.getDriver("chrome");
        try {
            testLogin();
            testLogout();
        } catch (Exception e) {
            System.out.println("FATAL: " + e.getMessage());
        } finally {
            driver.quit();
        }
    }

    static void testLogin() throws InterruptedException {
        System.out.println("\n====== LOGIN TEST ======");

        driver.get(URL);
        System.out.println("  Page    : " + driver.getTitle());

        driver.findElement(By.name("username")).sendKeys(USER);
        driver.findElement(By.name("password")).sendKeys(PASS);
        driver.findElement(By.cssSelector("button[type='submit']")).click();

        Thread.sleep(2000);

        boolean passed = driver.getCurrentUrl().contains("dashboard");
        System.out.println("  URL     : " + driver.getCurrentUrl());
        System.out.println("  Logged in as: "
            + driver.findElement(By.cssSelector(".oxd-userdropdown-name")).getText());
        System.out.println(passed ? "  ✓ PASS" : "  ✗ FAIL");
    }

    static void testLogout() throws InterruptedException {
        System.out.println("\n====== LOGOUT TEST ======");

        driver.findElement(By.cssSelector(".oxd-userdropdown-tab")).click();
        Thread.sleep(800);
        driver.findElement(By.xpath("//a[text()='Logout']")).click();
        Thread.sleep(1500);

        String url    = driver.getCurrentUrl();
        boolean passed = url.contains("login") || url.contains("auth");

        // Verify login form visible again
        boolean loginFormShown = driver.findElement(
            By.name("username")).isDisplayed();

        System.out.println("  URL         : " + url);
        System.out.println("  Login form  : " + loginFormShown);
        System.out.println(passed && loginFormShown ? "  ✓ PASS" : "  ✗ FAIL");
    }
}

package com.qaautomation.tests;

import com.qaautomation.utils.DriverFactory;
import org.openqa.selenium.*;

public class Day11Practice {

    static WebDriver driver;
    static final String URL = "https://opensource-demo.orangehrmlive.com";

    static void tryLogin(String user, String pass, String testName)
        throws InterruptedException {

        System.out.println("\n====== " + testName + " ======");
        driver.get(URL);

        // Fill form
        WebElement u = driver.findElement(By.name("username"));
        WebElement p = driver.findElement(By.name("password"));
        u.clear(); u.sendKeys(user);
        p.clear(); p.sendKeys(pass);
        driver.findElement(By.cssSelector("button[type='submit']")).click();

        Thread.sleep(2000);

        String url = driver.getCurrentUrl();
        boolean loggedIn = url.contains("dashboard");

        if (loggedIn) {
            String who = driver.findElement(
                By.cssSelector(".oxd-userdropdown-name")).getText();
            System.out.println("  Result: LOGIN SUCCESS");
            System.out.println("  User  : " + who);
        } else {
            // Check for error message
            List<WebElement> errors = driver.findElements(
                By.cssSelector(".oxd-alert-content"));
            String errMsg = errors.isEmpty() ? "No error shown" : errors.get(0).getText();
            System.out.println("  Result: LOGIN FAILED");
            System.out.println("  Error : " + errMsg);
        }
    }

    public static void main(String[] args) throws InterruptedException {
        driver = DriverFactory.getDriver("chrome");
        try {
            tryLogin("Admin",   "admin123", "TC01: Valid Login");
            tryLogin("Admin",   "wrongpass", "TC02: Wrong Password");
            tryLogin("baduser", "admin123", "TC03: Wrong Username");
        } finally {
            driver.quit();
            System.out.println("\nAll tests done. Browser closed.");
        }
    }
}

Common Mistakes

❌ Not calling clear() before sendKeys()

If a field has pre-filled text, sendKeys() appends to it. Always call clear() first: field.clear(); field.sendKeys("text");

❌ NoSuchElementException on slow pages

Element exists but page hasn't loaded it yet. Fix: increase implicit wait, or add Thread.sleep temporarily. Proper fix on Day 20: explicit wait.

❌ getText() vs getAttribute("value")

getText() gets visible text inside an element. getAttribute("value") gets the value of an input field. For form fields use getAttribute, for buttons/labels use getText.

❌ Hardcoding Thread.sleep()

Using Thread.sleep(10000) "to be safe" makes your suite hours long. Use realistic waits (1-3 seconds) as temporary measure. Day 20 replaces all of these.

❌ Wrong locator for submit button

OrangeHRM's Login button is button[type='submit'] not By.id("loginBtn"). Always inspect the actual element. Never guess locators.

❌ Not handling Thread.sleep InterruptedException

Thread.sleep() throws a checked exception. Either add throws InterruptedException to method signature or wrap in try-catch. Compiler won't let you forget.
