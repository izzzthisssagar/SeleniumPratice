Handling SSL Certificate Errors

Test environments often use self-signed SSL certificates that Chrome blocks with "Your connection is not private" error. Tell ChromeDriver to accept insecure certificates before creating the driver.

JavaSSLCertificate.java
import org.openqa.selenium.chrome.ChromeOptions;

// Method 1: Accept insecure certs via ChromeOptions (recommended)
ChromeOptions options = new ChromeOptions();
options.setAcceptInsecureCerts(true);  // accept self-signed certs

WebDriverManager.chromedriver().setup();
WebDriver driver = new ChromeDriver(options);

// Method 2: Via command-line args (alternative)
options.addArguments("--ignore-certificate-errors");
options.addArguments("--allow-insecure-localhost");

// Add to DriverFactory in the chrome case:
case "chrome":
    WebDriverManager.chromedriver().setup();
    ChromeOptions chromeOpts = new ChromeOptions();
    chromeOpts.setAcceptInsecureCerts(true);
    chromeOpts.addArguments("--disable-notifications");
    chromeOpts.addArguments("--disable-infobars");
    driver = new ChromeDriver(chromeOpts);
    break;

Browser Dialog Handling (Basic)

JavaScript dialogs (alert, confirm, prompt) block the browser. Selenium's Alert interface handles them. Full coverage on Day 21 — here's the essential pattern you need now.

JavaBasicAlerts.java
import org.openqa.selenium.Alert;
import org.openqa.selenium.NoAlertPresentException;

// Check if alert is present (safe check)
public static boolean isAlertPresent(WebDriver driver) {
    try {
        driver.switchTo().alert();
        return true;
    } catch (NoAlertPresentException e) {
        return false;
    }
}

// Accept (OK) an alert
public static void acceptAlert(WebDriver driver) {
    Alert alert = driver.switchTo().alert();
    System.out.println("Alert text: " + alert.getText());
    alert.accept();
}

// Dismiss (Cancel) a confirm dialog
public static void dismissAlert(WebDriver driver) {
    driver.switchTo().alert().dismiss();
}

// Type into a prompt dialog
public static void typeInAlert(WebDriver driver, String text) {
    Alert alert = driver.switchTo().alert();
    alert.sendKeys(text);
    alert.accept();
}

// Pattern: trigger alert, then handle it
((JavascriptExecutor) driver).executeScript("alert('Test Alert!')");
BrowserUtils.pause(500);
if (isAlertPresent(driver)) {
    acceptAlert(driver);
    System.out.println("Alert accepted");
}

Advanced Cookie Operations

JavaAdvancedCookies.java
import org.openqa.selenium.Cookie;
import java.util.*;

// Full cookie creation with all properties
Cookie fullCookie = new Cookie.Builder("sessionToken", "abc123xyz")
    .domain("opensource-demo.orangehrmlive.com")
    .path("/")
    .isSecure(true)
    .isHttpOnly(false)
    .build();
driver.manage().addCookie(fullCookie);

// Save all cookies to a Map (simulate "remember login" pattern)
Map<String, String> savedCookies = new HashMap<>();
for (Cookie c : driver.manage().getCookies()) {
    savedCookies.put(c.getName(), c.getValue());
}
System.out.println("Saved " + savedCookies.size() + " cookies");

// Restore cookies to new session (bypass login in tests)
driver.get("https://opensource-demo.orangehrmlive.com"); // must visit domain first
for (Map.Entry<String, String> entry : savedCookies.entrySet()) {
    driver.manage().addCookie(new Cookie(entry.getKey(), entry.getValue()));
}
driver.navigate().refresh();  // refresh to apply cookies

// Print cookie table
System.out.println("\n--- Cookies on current page ---");
System.out.printf("%-25s %-30s %-15s%n", "NAME", "VALUE", "SECURE");
System.out.println("-".repeat(72));
for (Cookie c : driver.manage().getCookies()) {
    String val = c.getValue() != null && c.getValue().length() > 28
        ? c.getValue().substring(0, 25) + "..." : c.getValue();
    System.out.printf("%-25s %-30s %-15s%n", c.getName(), val, c.isSecure());
}

Advanced JavascriptExecutor

JavaAdvancedJS.java
JavascriptExecutor js = (JavascriptExecutor) driver;

// ── Get element properties ────────────────────────────────────
WebElement el = driver.findElement(By.name("username"));

// Get computed style
String color = (String) js.executeScript(
    "return window.getComputedStyle(arguments[0]).color", el);
System.out.println("Text color: " + color);

// Get element dimensions via JS
Map<String, Object> rect = (Map) js.executeScript(
    "var r = arguments[0].getBoundingClientRect(); "
    + "return {top:r.top, left:r.left, width:r.width, height:r.height}", el);
System.out.println("Element bounds: " + rect);

// ── Modify DOM via JS ─────────────────────────────────────────
// Make hidden element visible
js.executeScript("arguments[0].style.display='block'", el);

// Remove an element
js.executeScript("arguments[0].remove()", el);

// Change element text
js.executeScript("arguments[0].innerText='New Text'", el);

// ── Page interaction ──────────────────────────────────────────
// Get total page height
Long height = (Long) js.executeScript("return document.body.scrollHeight");
System.out.println("Page height: " + height + "px");

// Get current scroll position
Long scrollY = (Long) js.executeScript("return window.pageYOffset");
System.out.println("Scroll Y: " + scrollY);

// Open new tab via JS
js.executeScript("window.open()");

// ── Async script ──────────────────────────────────────────────
// executeAsyncScript — useful for waiting on async operations

    "var cb = arguments[arguments.length-1]; "
    + "setTimeout(function(){ cb('done'); }, 1000);"

ScreenshotUtils — Full Implementation

⏰ Hour 2 — Utility Classes (60 mins)
JavaScreenshotUtils.java — utils/ScreenshotUtils.java
package com.qaautomation.utils;

import org.openqa.selenium.*;
import org.apache.commons.io.FileUtils;
import java.io.File;
import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;

public class ScreenshotUtils {

    private static final String SCREENSHOT_DIR = "screenshots/";

    // Ensure folder exists
    static {
        new File(SCREENSHOT_DIR).mkdirs();
    }

    // Take screenshot with timestamp in filename
    public static String take(WebDriver driver, String testName) {
        String timestamp = new SimpleDateFormat("yyyyMMdd_HHmmss").format(new Date());
        String fileName  = testName + "_" + timestamp + ".png";
        String filePath  = SCREENSHOT_DIR + fileName;

        try {
            File src  = ((TakesScreenshot) driver).getScreenshotAs(OutputType.FILE);
            File dest = new File(filePath);
            FileUtils.copyFile(src, dest);
            System.out.println("[SCRN] Saved: " + dest.getAbsolutePath());
            return dest.getAbsolutePath();
        } catch (IOException e) {
            System.out.println("[SCRN] Failed: " + e.getMessage());
            return null;
        }
    }

    // Take screenshot as Base64 (for HTML reports)
    public static String takeAsBase64(WebDriver driver) {
        return ((TakesScreenshot) driver).getScreenshotAs(OutputType.BASE64);
    }

    // Screenshot element only (not whole page)
    public static String takeElement(WebElement element, String name) {
        String timestamp = new SimpleDateFormat("yyyyMMdd_HHmmss").format(new Date());
        String filePath  = SCREENSHOT_DIR + name + "_" + timestamp + ".png";
        try {
            File src  = element.getScreenshotAs(OutputType.FILE);
            FileUtils.copyFile(src, new File(filePath));
            System.out.println("[SCRN] Element saved: " + filePath);
            return filePath;
        } catch (IOException e) {
            System.out.println("[SCRN] Element screenshot failed");
            return null;
        }
    }
}

// <dependency>
//   <groupId>commons-io</groupId>
//   <artifactId>commons-io</artifactId>
//   <version>2.15.1</version>
// </dependency>

ConfigReader — Reading from Properties File

Hard-coding URLs, usernames, and passwords directly in test code is bad practice. Store them in a config.properties file and read with ConfigReader. Swap environments (staging → production) by changing one file.

Propertiessrc/main/resources/config.properties
browser=chrome
base.url=https://opensource-demo.orangehrmlive.com
username=Admin
password=admin123
implicit.wait=10
page.load.timeout=30
JavaConfigReader.java — utils/ConfigReader.java
package com.qaautomation.utils;

import java.io.*;
import java.util.Properties;

public class ConfigReader {

    private static Properties properties;

    // Static block — load once when class is first used
    static {
        properties = new Properties();
        try {
            FileInputStream fis = new FileInputStream(
                "src/main/resources/config.properties");
            properties.load(fis);
        } catch (IOException e) {
            throw new RuntimeException("Cannot load config.properties", e);
        }
    }

    // Get any property by key
    public static String get(String key) {
        String value = properties.getProperty(key);
        if (value == null) {
            throw new RuntimeException("Property not found: " + key);
        }
        return value.trim();
    }

    // Convenience getters
    public static String getBrowser()     { return get("browser"); }
    public static String getBaseUrl()     { return get("base.url"); }
    public static String getUsername()    { return get("username"); }
    public static String getPassword()    { return get("password"); }
    public static int    getImplicitWait() { return Integer.parseInt(get("implicit.wait")); }
    public static int    getPageLoadTimeout() { return Integer.parseInt(get("page.load.timeout")); }
}

// Usage in any class:
String url  = ConfigReader.getBaseUrl();   // https://opensource-demo.orangehrmlive.com
String user = ConfigReader.getUsername();  // Admin
String pass = ConfigReader.getPassword();  // admin123
🌟
Update DriverFactory to use ConfigReader

Now update your DriverFactory to read browser type and timeouts from config.properties instead of hardcoding: String browser = ConfigReader.getBrowser();. This is how professional frameworks separate test data from test logic.

package com.qaautomation.tests;

        WebDriver driver = DriverFactory.getDriver(ConfigReader.getBrowser());

            System.out.println("  testSession: " + (tc != null ? tc.getValue() : "null"));

            String state  = js.executeScript("return document.readyState").toString();
            Long height   = (Long) js.executeScript("return document.body.scrollHeight");
            String jsTitle = js.executeScript("return document.title").toString();
            System.out.println("  readyState : " + state);
            System.out.println("  page height: " + height + "px");
            System.out.println("  JS title   : " + jsTitle);
            BrowserUtils.scrollToBottom(driver);
            BrowserUtils.pause(300);
            BrowserUtils.scrollToTop(driver);
            System.out.println("  Scrolled up and down");

            // Task 4: Alert via JS
            System.out.println("\n====== TASK 4: Alert ======");
            js.executeScript("alert('Day 13 Test!')");
            BrowserUtils.pause(500);
            Alert alert = driver.switchTo().alert();
            System.out.println("  Alert text : " + alert.getText());
            alert.accept();
            System.out.println("  Alert accepted");

            // Task 5: BrowserUtils assertions
            System.out.println("\n====== TASK 5: Assertions ======");
            System.out.println("  titleEquals    : " + BrowserUtils.titleEquals(driver, "OrangeHRM"));
            System.out.println("  urlContains    : " + BrowserUtils.urlContains(driver, "orangehrm"));
            System.out.println("  isPageLoaded   : " + BrowserUtils.isPageLoaded(driver));

        } catch (Exception e) {
            ScreenshotUtils.take(driver, "day13_error");
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ config.properties path wrong

If you get "Cannot load config.properties", the path must be relative to project root: src/main/resources/config.properties. Create the resources folder first.

❌ Screenshots folder not created

If screenshots/ folder doesn't exist, FileUtils.copyFile() throws IOException. The static block in ScreenshotUtils handles this with new File(SCREENSHOT_DIR).mkdirs(). Don't remove it.

❌ Switching to alert before it appears

driver.switchTo().alert() immediately after triggering JS throws NoAlertPresentException if the alert hasn't rendered yet. Add a small pause or use explicit wait (Day 20).

❌ JS executeScript casting

executeScript returns Object. If you try to cast to wrong type (e.g., cast Long to String), ClassCastException. Always match the type to what the JS actually returns.

❌ setAcceptInsecureCerts after driver created

SSL options must be set in ChromeOptions BEFORE new ChromeDriver(options). You can't change them after the driver is launched.

❌ ConfigReader property not found

If a key doesn't exist in config.properties, ConfigReader throws RuntimeException. Verify the exact key spelling — property names are case-sensitive.
