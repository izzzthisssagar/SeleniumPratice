What is XPath?

⏰ Hour 1 — XPath Fundamentals (60 mins)

XPath (XML Path Language) is a query language for navigating HTML/XML documents. It can locate any element using its position, attributes, text content, or relationship to other elements. It's the most powerful Selenium locator — and the one you'll use when id and name aren't available.

📌
When to use XPath over id/name

Element has no id or name → Use CSS or XPath. Need to find by visible text → XPath only. Need to navigate to a parent/sibling element → XPath axes. Need to combine attribute + text conditions → XPath. CSS can't do parent traversal — XPath can.

Absolute vs Relative XPath

TypeStarts WithExampleUse?
Absolute/html/body/.../html/body/div[2]/form/input[1]❌ NEVER — breaks on any HTML change
Relative////input[@name='username']✅ Always use this
XPathAbsolute vs Relative
// ABSOLUTE — fragile, breaks if ANY parent element changes
// /html/body/div[3]/div/div[2]/form/div/div[1]/div/div/input
// This is what Chrome "Copy XPath" gives you — NEVER use it

// RELATIVE — starts with // — searches anywhere in the document
// //input[@name='username']
// Much more stable — only breaks if the element itself changes

// Java usage
// By.xpath("/html/body/div[3]/...")  ← NEVER
// By.xpath("//input[@name='username']")  ← ALWAYS
🚨
Never use "Copy XPath" from Chrome DevTools

The XPath Chrome generates (right-click → Copy → Copy XPath) creates an ABSOLUTE XPath. It works today, breaks tomorrow when developers add one div. Always write your own relative XPath starting with //.

04

XPath Attributes — @attr

XPath + JavaAttributes.java
// Single attribute
By.xpath("//input[@name='username']")
By.xpath("//button[@type='submit']")
By.xpath("//input[@placeholder='Username']")
By.xpath("//a[@href='/forgot-password']")

// Any tag with attribute — use * wildcard
By.xpath("//*[@id='loginBtn']")         // any tag with this id
By.xpath("//*[@type='submit']")         // any tag with type=submit
By.xpath("//*[@class='error-message']") // any tag with this exact class

// Check attribute existence (not value)
By.xpath("//input[@disabled]")     // any disabled input
By.xpath("//input[@readonly]")     // any readonly input
By.xpath("//input[@required]")     // any required input

// Negate — NOT having an attribute
By.xpath("//input[not(@disabled)]") // enabled inputs only
05

XPath Functions — text(), contains(), starts-with()

These three functions are the most used in real Selenium frameworks. Master them.

XPath + JavaXPath_Functions.java
// ── text() — match element's visible text ─────────────────────
// //tagname[text()='exact text']
By.xpath("//button[text()='Login']")          // exact match
By.xpath("//h6[text()='Dashboard']")          // heading text
By.xpath("//a[text()='Logout']")              // link text exact match
By.xpath("//label[text()='Username']")        // form label
By.xpath("//td[text()='John Smith']")         // table cell by text

// ── contains() — partial match ────────────────────────────────
// Handles dynamic text, long strings, partial class names
By.xpath("//button[contains(text(),'Log')]")       // "Login" or "Logout" or "Log In"
By.xpath("//div[contains(@class,'alert')]")       // class contains 'alert'
By.xpath("//a[contains(@href,'forgot')]")        // href contains 'forgot'
By.xpath("//input[contains(@placeholder,'name')]") // placeholder has 'name'
By.xpath("//p[contains(text(),'Invalid')]")       // error text has 'Invalid'

// ── starts-with() — prefix match ──────────────────────────────
By.xpath("//input[starts-with(@id,'txt')]")     // id starts with 'txt'
By.xpath("//div[starts-with(@class,'oxd')]")    // class starts with 'oxd'
By.xpath("//a[starts-with(@href,'/dash')]")    // href starts with '/dash'

// ── normalize-space() — trim whitespace ───────────────────────
// Handles elements where text has extra spaces or newlines
By.xpath("//button[normalize-space()='Login']")
By.xpath("//td[normalize-space(text())='John']")

// ── string-length() ───────────────────────────────────────────
By.xpath("//input[string-length(@value) > 0]")  // non-empty inputs
✅
contains() is your most useful XPath function

contains(@class, 'oxd') finds elements whose class CONTAINS 'oxd' — perfect for elements with multiple dynamic classes. contains(text(), 'Invalid') finds error messages without matching the exact full string. Use it constantly.

XPath Axes — parent, child, sibling, following

Axes let you navigate to related elements — find an element's parent, sibling, or elements that come after/before it. This is what makes XPath uniquely powerful compared to CSS selectors.

AxisSyntaxFinds
parent:://input/parent::divDirect parent div of the input
child:://form/child::inputDirect children inputs of form
ancestor:://input/ancestor::formAny ancestor form element
descendant:://form/descendant::inputAll input elements inside form
following-sibling:://label/following-sibling::inputInput that comes after label (same parent)
preceding-sibling:://input/preceding-sibling::labelLabel that comes before input
following:://div[@class='title']/following::inputAll inputs after that div (any level)
XPath + JavaXPath_Axes.java
// Real scenario: find input field by its label text
// HTML: <label>Username</label> <input name="username">

// Find the input that follows the "Username" label
By.xpath("//label[text()='Username']/following-sibling::input")

// Find parent div of login button (to get its container)
By.xpath("//button[@type='submit']/parent::div")

// Find all inputs inside a specific form
By.xpath("//form[@id='loginForm']/descendant::input")

// Find the error message that appears after a failed field
By.xpath("//input[@name='username']/following-sibling::span[@class='error']")

// Find row in table that contains "John Smith", then get the edit button
By.xpath("//tr[td[text()='John Smith']]//button[@title='Edit']")

// Ancestor — find the form that contains a specific input
By.xpath("//input[@name='username']/ancestor::form")

XPath Position — [1], [last()], position()

When multiple elements match your XPath, use position to get a specific one.

XPath + JavaXPath_Position.java
// Get first matching element (index starts at 1, not 0!)
By.xpath("(//input[@type='text'])[1]")       // first text input
By.xpath("(//input[@type='text'])[2]")       // second text input

// Get last matching element
By.xpath("(//input[@type='text'])[last()]")  // last text input
By.xpath("(//tr)[last()]")                  // last table row

// Position-based conditions
By.xpath("(//li)[position() < 4]")          // first 3 list items
By.xpath("(//tr)[position() > 1]")          // all rows except header

// Get Nth table row (header = row 1, data starts at row 2)
By.xpath("(//table)[1]//tr[2]")           // first data row of first table
By.xpath("(//table)[1]//tr[3]/td[2]")      // 3rd row, 2nd column

// Important: wrap in () when using position with // searches
// //input[@type='text'][1] ← finds first text input within group
// (//input[@type='text'])[1] ← finds globally first text input
// These can return different results!

// Java examples
WebElement firstRow  = driver.findElement(By.xpath("(//tr)[2]"));
WebElement lastInput  = driver.findElement(By.xpath("(//input)[last()]"));
List<WebElement> rows = driver.findElements(By.xpath("//tbody/tr"));
System.out.println("Data rows: " + rows.size());
08

Combining Conditions — and, or

XPath + JavaXPath_Conditions.java
// AND — element must satisfy BOTH conditions
By.xpath("//input[@type='text' and @name='username']")
By.xpath("//button[@type='submit' and contains(text(),'Login')]")
By.xpath("//div[contains(@class,'alert') and contains(@class,'danger')]")

// OR — element must satisfy EITHER condition
By.xpath("//input[@type='text' or @type='email']")
By.xpath("//button[text()='Login' or text()='Sign In']")

// Multiple conditions combined
By.xpath("//input[@name='username' and @type='text' and not(@disabled)]")

// NOT — element does NOT match condition
By.xpath("//input[not(@type='hidden')]")     // non-hidden inputs
By.xpath("//button[not(@disabled)]")          // enabled buttons
By.xpath("//div[not(contains(@class,'hide'))]") // visible divs

// Multiple element types (pipe = OR in XPath 2.0, use this syntax)
By.xpath("//input | //select | //textarea")  // all form fields

Complex XPath — Real World Examples

⏰ Hour 2 — Complex Scenarios (60 mins)
XPath + JavaComplexXPath.java
// ── TABLE: Find edit button in specific row ───────────────────
// HTML: <tr><td>John Smith</td><td><button>Edit</button></td></tr>
By.xpath("//tr[td[text()='John Smith']]//button[text()='Edit']")
// Meaning: find tr that HAS a td with 'John Smith', then find button 'Edit' inside it

// ── DROPDOWN: Find option by text ────────────────────────────
By.xpath("//select[@name='country']/option[text()='Nepal']")
By.xpath("//select[@id='empStatus']//option[contains(text(),'Full')]")

// ── DYNAMIC: Element with partial id ─────────────────────────
// id="panel-collapse-12345" — number changes each load
By.xpath("//div[starts-with(@id,'panel-collapse')]")
By.xpath("//div[contains(@id,'collapse')]")

// ── FORM LABEL: Input after specific label ────────────────────
// HTML: <div><label>First Name</label><input name="firstName"></div>
By.xpath("//label[text()='First Name']/following-sibling::input")
// OR navigate via parent
By.xpath("//label[contains(text(),'First')]/parent::div//input")

// ── CHECKBOX: Find checked checkbox ──────────────────────────
By.xpath("//input[@type='checkbox' and @checked]")
By.xpath("//input[@type='checkbox'][not(@checked)]") // unchecked

// ── OrangeHRM: Find employee row by name in PIM table ────────
By.xpath("//div[@class='oxd-table-body']//div[contains(.,'John Smith')]")
// Note: contains(., 'text') checks text content of element AND its children

// ── NAVIGATION: Find active menu item ────────────────────────
By.xpath("//li[contains(@class,'active')]//a")

// ── MULTIPLE COLUMNS: Get specific column value from row ──────
// Table row 3, column 2 content
By.xpath("//table//tr[3]/td[2]")

// All "Status" column values (column 4 in all rows)
List<WebElement> statusCells = driver.findElements(By.xpath("//tbody/tr/td[4]"));
statusCells.forEach(c -> System.out.println(c.getText()));

XPath vs CSS Selector — When to Use Which

ScenarioUseReason
Find by visible textXPathCSS can't match text content. XPath has text()
Navigate to parent elementXPathCSS has no parent selector. XPath has parent::
Navigate to siblingXPathXPath axes; CSS can only do following-sibling with +
Find by class (single)CSSSimpler syntax: .myClass vs contains(@class,'myClass')
Find by idEitherCSS: #id — XPath: //*[@id='id'] — both fine
Find by multiple classesCSS.class1.class2 vs contains(@class,'c1') and contains(@class,'c2')
Complex dynamic locatorsXPathcontains(), starts-with() make dynamic ids workable
PerformanceCSS (slightly)CSS selectors are parsed natively by browser — marginally faster
🌟
Professional preference in industry

Most senior QAs use CSS selectors for class/attribute-based locators and XPath for text-based or relational locators. Build fluency in both — never limit yourself to one. The best locator for a given element is the one that's most specific, readable, and stable.

Practice Task + Expected Output

JavaDay15Practice.java
package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import java.util.List;

public class Day15Practice {

    // XPath locators as constants
    static final By USERNAME   = By.xpath("//input[@name='username']");
    static final By PASSWORD   = By.xpath("//input[@name='password']");
    static final By LOGIN_BTN  = By.xpath("//button[@type='submit']");
    static final By ERROR_MSG  = By.xpath("//p[contains(@class,'alert')]");
    static final By DASHBOARD  = By.xpath("//h6[text()='Dashboard']");
    static final By USER_NAME  = By.xpath("//span[contains(@class,'userdropdown-name')]");
    static final By ALL_INPUTS = By.xpath("//input[not(@type='hidden')]");

    public static void main(String[] args) throws InterruptedException {
        WebDriver driver = DriverFactory.getDriver("chrome");

        try {
            driver.get(ConfigReader.getBaseUrl());

            // Task 1: Find elements using XPath
            System.out.println("====== TASK 1: XPath Locators ======");
            System.out.println("  Username found  : " + driver.findElement(USERNAME).isDisplayed());
            System.out.println("  Password found  : " + driver.findElement(PASSWORD).isDisplayed());
            System.out.println("  Login btn found : " + driver.findElement(LOGIN_BTN).isEnabled());

            // Task 2: All visible inputs via XPath
            System.out.println("\n====== TASK 2: All Inputs ======");
            List<WebElement> inputs = driver.findElements(ALL_INPUTS);
            System.out.println("  Visible inputs: " + inputs.size());
            for (WebElement i : inputs) {
                System.out.println("  → type=" + i.getAttribute("type")
                    + "  name=" + i.getAttribute("name"));
            }

            // Task 3: Login with XPath locators
            System.out.println("\n====== TASK 3: Login Flow ======");
            driver.findElement(USERNAME).sendKeys(ConfigReader.getUsername());
            driver.findElement(PASSWORD).sendKeys(ConfigReader.getPassword());
            driver.findElement(LOGIN_BTN).click();
            Thread.sleep(2000);

            boolean dashboardVisible = !driver.findElements(DASHBOARD).isEmpty();
            String loggedUser = driver.findElement(USER_NAME).getText();
            System.out.println("  Dashboard header: " + dashboardVisible);
            System.out.println("  Logged in as   : " + loggedUser);
            System.out.println(dashboardVisible ? "  ✓ PASS" : "  ✗ FAIL");

            // Task 4: contains() XPath — error message
            System.out.println("\n====== TASK 4: contains() XPath ======");
            driver.get(ConfigReader.getBaseUrl());
            driver.findElement(USERNAME).sendKeys("baduser");
            driver.findElement(PASSWORD).sendKeys("badpass");
            driver.findElement(LOGIN_BTN).click();
            Thread.sleep(1500);

            boolean errorShown = !driver.findElements(ERROR_MSG).isEmpty();
            System.out.println("  Error shown: " + errorShown);
            if (errorShown)
                System.out.println("  Error text : " + driver.findElement(ERROR_MSG).getText());
            System.out.println(errorShown ? "  ✓ PASS" : "  ✗ FAIL");

            // Task 5: XPath with text() function
            System.out.println("\n====== TASK 5: text() Function ======");
            WebElement forgotLink = driver.findElement(
                By.xpath("//a[contains(text(),'Forgot')]"));
            System.out.println("  Forgot link text: " + forgotLink.getText());
            System.out.println("  Forgot link href: " + forgotLink.getAttribute("href"));
            System.out.println("  ✓ PASS");

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ Using absolute XPath

Never use XPath copied from Chrome DevTools — it starts with /html/body/... and breaks on any HTML change. Always write relative XPath starting with //

❌ text() vs contains(text())

text()='Login' requires EXACT match including whitespace. contains(text(),'Login') is safer — matches even if there are extra spaces or the text is part of a longer string.

❌ XPath index starts at 1

In XPath, [1] is the first element, not [0]. Using [0] returns nothing (no exception, just empty). This is opposite to Java arrays and Lists.

❌ Missing parentheses with position

//input[1] vs (//input)[1] can give different results. The first finds the first input within each parent group; the second finds globally the first input. Always use parentheses.

❌ @class exact match is fragile

@class='oxd-input' fails if the element has additional classes like class='oxd-input oxd-input--active'. Use contains(@class,'oxd-input') instead.

❌ Forgetting // before axes

//div/following::input — correct. //div/following/input — wrong (missing ::). All axis names need double colon: parent::, child::, following-sibling::, etc.
