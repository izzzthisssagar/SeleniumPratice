What is the Actions Class?

⏰ Hour 1 — Mouse Actions (60 mins)

The Actions class simulates complex user interactions that element.click() can't handle — mouse hover, right-click, double-click, drag-and-drop, and keyboard combinations. It builds a chain of actions and executes them all at once with perform().

ActionMethodUse Case
Mouse hovermoveToElement(el)Show tooltips, reveal hidden menus, dropdown reveals
Right-clickcontextClick(el)Open context menu, right-click menus
Double-clickdoubleClick(el)Select all text in input, open edit mode in tables
Click and holdclickAndHold(el)Drag start, slider controls
Drag and dropdragAndDrop(src, tgt)Sortable lists, Kanban boards, file managers
Key + clickkeyDown(Keys.CONTROL) + clickMulti-select with Ctrl+click
Scroll by amountscrollByAmount(x, y)Scroll page or element by pixels
Scroll to elementscrollToElement(el)Bring element into viewport

Actions Architecture — Build & Perform

// Actions Pattern — Always ends with perform()
JavaActions_Setup.java
import org.openqa.selenium.interactions.Actions;

// Create Actions object — needs driver reference
Actions actions = new Actions(driver);

// Pattern: chain methods, end with perform()
actions.moveToElement(element)
       .click()
       .perform();  // ← REQUIRED — nothing happens without this

// Short syntax for single actions
new Actions(driver).moveToElement(element).perform();
new Actions(driver).doubleClick(element).perform();
new Actions(driver).contextClick(element).perform();

Mouse Hover — moveToElement()

Hover reveals hidden elements — dropdown menus, tooltips, sub-menus. Many navigation menus only show sub-items when you hover over the parent.

JavaMouseHover.java
Actions actions = new Actions(driver);

// Basic hover
WebElement menuItem = driver.findElement(By.cssSelector(".nav-item"));
actions.moveToElement(menuItem).perform();
Thread.sleep(500); // wait for sub-menu to appear

// Hover then click sub-menu item
WebElement subMenu = driver.findElement(By.cssSelector(".sub-menu-item"));
actions.moveToElement(menuItem)
       .moveToElement(subMenu)
       .click()
       .perform();

// Hover to reveal tooltip
WebElement icon = driver.findElement(By.cssSelector(".info-icon"));
actions.moveToElement(icon).perform();
Thread.sleep(500);
WebElement tooltip = driver.findElement(By.cssSelector(".tooltip"));
System.out.println("Tooltip: " + tooltip.getText());

// Hover with offset (hover to specific coordinates within element)
actions.moveToElement(menuItem, 10, 5).perform(); // offset x=10, y=5 from center

// OrangeHRM — hover over user dropdown to see options
WebElement userMenu = driver.findElement(By.cssSelector(".oxd-userdropdown"));
actions.moveToElement(userMenu).perform();
Thread.sleep(300);

Click and Hold — clickAndHold()

JavaClickHold.java
Actions actions = new Actions(driver);

// Hold mouse button down on element
WebElement element = driver.findElement(By.id("sliderHandle"));
actions.clickAndHold(element)
       .moveByOffset(100, 0)  // move 100px to the right while holding
       .release()              // release the mouse button
       .perform();

// Slider example — move from left to right
WebElement slider = driver.findElement(By.cssSelector("input[type='range']"));
actions.clickAndHold(slider)
       .moveByOffset(50, 0)
       .release()
       .perform();
System.out.println("Slider value: " + slider.getAttribute("value"));

// Move to exact coordinates (from top-left of page)
actions.moveToLocation(500, 300).click().perform();

// Move relative to current position
actions.moveByOffset(50, 100).perform(); // move 50px right, 100px down

Drag and Drop

JavaDragDrop.java
Actions actions = new Actions(driver);

// Method 1: dragAndDrop(source, target) — simplest
WebElement source = driver.findElement(By.id("draggable"));
WebElement target = driver.findElement(By.id("droppable"));
actions.dragAndDrop(source, target).perform();
Thread.sleep(500);
System.out.println("Dragged and dropped");

// Method 2: dragAndDropBy(source, xOffset, yOffset)
actions.dragAndDropBy(source, 200, 0).perform(); // drag 200px right

// Method 3: Manual — clickAndHold + moveToElement + release
// More reliable on some modern apps
actions.clickAndHold(source)
       .moveToElement(target)
       .release()
       .perform();

// Practice on DemoQA
driver.get("https://demoqa.com/droppable");
WebElement drag = driver.findElement(By.id("draggable"));
WebElement drop = driver.findElement(By.id("droppable"));
actions.dragAndDrop(drag, drop).perform();
Thread.sleep(500);
String dropText = drop.getText();
System.out.println("Drop zone text: " + dropText); // "Dropped!"

// Verify drag-and-drop succeeded
boolean success = dropText.contains("Dropped");
System.out.println(success ? "✓ Drop successful" : "✗ Drop failed");

Keyboard Actions — sendKeys, keyDown, keyUp

JavaKeyboardActions.java
import org.openqa.selenium.Keys;

Actions actions = new Actions(driver);

// sendKeys via Actions (types into currently focused element)
actions.sendKeys("Hello World").perform();
actions.sendKeys(Keys.ENTER).perform();
actions.sendKeys(Keys.TAB).perform();

// sendKeys on specific element
WebElement field = driver.findElement(By.name("username"));
actions.click(field).sendKeys("Admin").perform();

// Ctrl+A then type (clear + type in one action)
actions.click(field)
       .keyDown(Keys.CONTROL)
       .sendKeys("a")
       .keyUp(Keys.CONTROL)
       .sendKeys("NewText")
       .perform();

// Ctrl+Click — multi-select in a list
WebElement item1 = driver.findElement(By.cssSelector("li:nth-child(1)"));
WebElement item3 = driver.findElement(By.cssSelector("li:nth-child(3)"));
actions.click(item1)
       .keyDown(Keys.CONTROL)
       .click(item3)
       .keyUp(Keys.CONTROL)
       .perform();

// Shift+Click — range select
actions.click(item1)
       .keyDown(Keys.SHIFT)
       .click(item3)
       .keyUp(Keys.SHIFT)
       .perform();

// Copy-paste via keyboard
actions.keyDown(Keys.CONTROL).sendKeys("c").keyUp(Keys.CONTROL).perform(); // copy
actions.keyDown(Keys.CONTROL).sendKeys("v").keyUp(Keys.CONTROL).perform(); // paste

// keyDown/keyUp — modifier keys that stay pressed
// keyDown(Keys.SHIFT) + sendKeys("hello") = "HELLO"
actions.keyDown(Keys.SHIFT)
       .sendKeys("hello")
       .keyUp(Keys.SHIFT)
       .perform(); // types "HELLO"

Chaining Multiple Actions

JavaChainedActions.java
Actions actions = new Actions(driver);

// Chain: hover menu → hover sub-menu → click
WebElement topMenu = driver.findElement(By.cssSelector(".top-menu"));
WebElement subMenu = driver.findElement(By.cssSelector(".sub-menu-item"));

actions.moveToElement(topMenu)      // hover parent
       .pause(300)                   // pause 300ms for animation
       .moveToElement(subMenu)       // hover child
       .pause(200)
       .click()                      // click sub-item
       .perform();

// Chain: select all text + type replacement
WebElement input = driver.findElement(By.name("username"));
actions.click(input)
       .keyDown(Keys.CONTROL)
       .sendKeys("a")
       .keyUp(Keys.CONTROL)
       .sendKeys("NewUsername")
       .perform();
System.out.println("Value: " + input.getAttribute("value")); // NewUsername

// Chain: right-click + select context option
WebElement rightClickTarget = driver.findElement(By.id("tableRow"));
actions.contextClick(rightClickTarget).perform();
Thread.sleep(300);
driver.findElement(By.xpath("//li[text()='Delete']")).click();

Scroll Actions (Selenium 4)

⏰ Hour 2 — Scroll, Tooltips & Practice (60 mins)
JavaScrollActions.java
Actions actions = new Actions(driver);

// Selenium 4 native scroll — NO JavaScript needed!

// Scroll down by pixels from current position
actions.scrollByAmount(0, 500).perform(); // scroll down 500px
actions.scrollByAmount(0, -300).perform(); // scroll up 300px
actions.scrollByAmount(200, 0).perform(); // scroll right 200px

// Scroll until specific element is in view
WebElement footer = driver.findElement(By.cssSelector("footer"));
actions.scrollToElement(footer).perform();
Thread.sleep(300);
System.out.println("Scrolled to footer");

// Scroll within a scrollable element (not the page)
WebElement scrollableDiv = driver.findElement(By.cssSelector(".scrollable-list"));
actions.scrollFromOrigin(
    org.openqa.selenium.interactions.WheelInput.ScrollOrigin.fromElement(scrollableDiv),
    0, 100  // scroll within this element
).perform();

// JS scroll still works too (from Day 12):
((JavascriptExecutor) driver).executeScript(
    "arguments[0].scrollIntoView(true)", footer);

Tooltip Verification

JavaTooltipVerify.java
Actions actions = new Actions(driver);

// METHOD 1: title attribute tooltip (easiest)
// HTML: <button title="Save your changes">Save</button>
WebElement saveBtn = driver.findElement(By.id("saveBtn"));
String titleTooltip = saveBtn.getAttribute("title");
System.out.println("Tooltip (title): " + titleTooltip);
boolean passed = titleTooltip.equals("Save your changes");
System.out.println(passed ? "✓ PASS" : "✗ FAIL");

// METHOD 2: CSS tooltip — appears on hover as div
// HTML: <span class="info-icon">?</span>
//       <div class="tooltip" hidden>More info here</div>
WebElement infoIcon = driver.findElement(By.cssSelector(".info-icon"));
actions.moveToElement(infoIcon).perform();
Thread.sleep(500); // wait for tooltip to render
WebElement tooltip = driver.findElement(By.cssSelector(".tooltip"));
System.out.println("Tooltip visible: " + tooltip.isDisplayed());
System.out.println("Tooltip text   : " + tooltip.getText());

// METHOD 3: aria-label attribute
// HTML: <button aria-label="Delete this record"></button>
String ariaLabel = saveBtn.getAttribute("aria-label");
System.out.println("Aria label: " + ariaLabel);

ActionsHelper Utility

JavaActionsHelper.java — utils/ActionsHelper.java
package com.qaautomation.utils;

import org.openqa.selenium.*;
import org.openqa.selenium.interactions.Actions;

public class ActionsHelper {

    public static void hover(WebDriver driver, WebElement el) {
        new Actions(driver).moveToElement(el).perform();
    }

    public static void rightClick(WebDriver driver, WebElement el) {
        new Actions(driver).contextClick(el).perform();
    }

    public static void doubleClick(WebDriver driver, WebElement el) {
        new Actions(driver).doubleClick(el).perform();
    }

    public static void dragAndDrop(WebDriver driver,
            WebElement source, WebElement target) {
        new Actions(driver).dragAndDrop(source, target).perform();
    }

    public static void scrollDown(WebDriver driver, int pixels) {
        new Actions(driver).scrollByAmount(0, pixels).perform();
    }

    public static void scrollToElement(WebDriver driver, WebElement el) {
        new Actions(driver).scrollToElement(el).perform();
    }

    public static void hoverAndClick(WebDriver driver,
            WebElement hoverEl, WebElement clickEl) {
        new Actions(driver)
            .moveToElement(hoverEl)
            .pause(300)
            .moveToElement(clickEl)
            .click()
            .perform();
    }

    public static String getTooltip(WebElement el) {
        String title     = el.getAttribute("title");
        String ariaLabel = el.getAttribute("aria-label");
        if (title != null && !title.isEmpty())     return title;
        if (ariaLabel != null && !ariaLabel.isEmpty()) return ariaLabel;
        return "";
    }
}

package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import org.openqa.selenium.interactions.Actions;

public class Day19Practice {

    public static void main(String[] args) throws InterruptedException {
        WebDriver driver = DriverFactory.getDriver("chrome");
        Actions actions = new Actions(driver);

            String title = driver.getTitle();

            actions.scrollByAmount(0, 500).perform();
            Thread.sleep(300);
            System.out.println("  Scrolled down 500px");
            actions.scrollByAmount(0, -500).perform();
            Thread.sleep(300);
            System.out.println("  Scrolled back to top");
            System.out.println("  ✓ PASS");

            // Task 4: OrangeHRM hover + scroll
            System.out.println("\n====== TASK 4: OrangeHRM Hover ======");
            driver.get(ConfigReader.getBaseUrl());
            driver.findElement(By.name("username")).sendKeys(ConfigReader.getUsername());
            driver.findElement(By.name("password")).sendKeys(ConfigReader.getPassword());
            driver.findElement(By.cssSelector("button[type='submit']")).click();
            Thread.sleep(2000);

            // Hover over user dropdown
            WebElement userDrop = driver.findElement(
                By.cssSelector(".oxd-userdropdown"));
            actions.moveToElement(userDrop).perform();
            Thread.sleep(400);
            System.out.println("  Hovered user dropdown");

            // Click it to open
            userDrop.click();
            Thread.sleep(400);
            boolean logoutVisible = !driver.findElements(
                By.xpath("//a[text()='Logout']")).isEmpty();
            System.out.println("  Logout visible: " + logoutVisible);
            System.out.println(logoutVisible ? "  ✓ PASS" : "  ✗ FAIL");

            // Scroll down on dashboard
            actions.scrollByAmount(0, 300).perform();
            Thread.sleep(300);
            System.out.println("  Scrolled dashboard ✓");

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ Forgetting perform()

Building an Actions chain without calling .perform() at the end — nothing happens. perform() is mandatory. It's the most common Actions mistake.

❌ Hover without pause

Hovering and immediately looking for sub-menu items — they haven't appeared yet. Add .pause(300) in the chain or a Thread.sleep(500) after perform().

❌ dragAndDrop not working

Some modern apps ignore the standard drag-and-drop event. Try the manual approach: clickAndHold().moveToElement().pause(500).release(). HTML5 canvas drag may need JS dispatch events.

❌ keyDown without keyUp

Calling keyDown(Keys.SHIFT) without keyUp(Keys.SHIFT) leaves the modifier key stuck — all subsequent typing will be in uppercase/shifted. Always pair keyDown with keyUp.

❌ moveToElement on hidden element

Hovering an element with visibility:hidden or display:none throws MoveTargetOutOfBoundsException. The element must be visible and in the viewport.

❌ scrollByAmount vs scrollToElement

scrollByAmount(0, 500) scrolls by pixels from current position. scrollToElement(el) scrolls until element is visible. Use scrollToElement when you need a specific element in view.
