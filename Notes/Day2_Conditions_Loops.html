Why Conditions & Loops Matter in Selenium

Every meaningful Selenium script uses conditions and loops. Without them, your test code is just a linear list of steps — it can't make decisions, handle failures, or repeat actions. Here's exactly how you'll use them once you reach Selenium:

ConceptReal Selenium Usage
if / elseCheck if a button is enabled before clicking. If login failed, skip rest of test.
if-else ifDifferent actions based on browser type: Chrome vs Firefox vs Edge.
for loopLoop through all rows in a table to verify each value.
while loopKeep retrying an action until element appears (custom wait logic).
for-eachIterate through all WebElement objects returned by findElements().
breakStop searching through a list once the target element is found.
continueSkip disabled or hidden elements in a list while processing others.
switchPick which browser driver to initialize based on a config value.

02

Comparison Operators

⏱ Hour 1 — Conditions (60 mins)

Comparison operators compare two values and return a boolean — either true or false. These go inside if conditions.

OperatorMeaningExampleResult
==Equal to5 == 5true
!=Not equal to5 != 3true
>Greater than10 > 5true
<Less than3 < 8true
>=Greater than or equal5 >= 5true
<=Less than or equal4 <= 3false
🚨
= vs == — The #1 Beginner Bug

= is assignment: puts a value INTO a variable. == is comparison: checks if two values are EQUAL. Writing if (x = 5) instead of if (x == 5) is a logic bug that's hard to spot. Never mix them up.

03

Logical Operators

Logical operators combine multiple conditions together. You'll use these constantly in Selenium when you need to check more than one thing at once.

OperatorNameMeaningExampleResult
&&ANDBoth conditions must be trueage > 18 && isActivetrue only if BOTH true
||ORAt least one must be trueisAdmin || isUsertrue if EITHER true
!NOTReverses the boolean!isLoggedIntrue if isLoggedIn is false
// Truth Tables — AND · OR · NOT
JavaLogicalOperators.java
boolean isLoggedIn  = true;
boolean isAdmin     = false;
int     age         = 22;

// AND — both must be true
if (isLoggedIn && isAdmin) {
    System.out.println("Show admin dashboard");
} else {
    System.out.println("Access denied");   // prints this
}

// OR — at least one must be true
if (isLoggedIn || isAdmin) {
    System.out.println("Allow access");      // prints this
}

// NOT — reverses the boolean
if (!isAdmin) {
    System.out.println("User is NOT an admin"); // prints this
}

// Combining operators
if (age >= 18 && isLoggedIn && !isAdmin) {
    System.out.println("Standard user — age verified"); // prints
}
04

if Statement

The simplest form. Code inside the block runs only if the condition is true. If false, the block is skipped entirely.

// if Statement — Flow Diagram
JavaIfStatement.java
int score = 85;

// Basic if — only runs if score > 80
if (score > 80) {
    System.out.println("Test passed with high score!");
}
// Output: Test passed with high score!

// If only one line — braces optional (but ALWAYS use them)
if (score > 80)
    System.out.println("Passed");  // works but risky

// Selenium example: only click if button is enabled
boolean isButtonEnabled = true;
if (isButtonEnabled) {
    System.out.println("Clicking submit button");
    // submitButton.click(); ← actual Selenium code (Day 9+)
}
⚡
Always Use Braces { } — Even for One Line

Skipping braces for single-line if is valid Java but a bad habit. When you add a second line later, forgetting to add braces causes a silent logic bug that's painful to debug. Always use { }.

05

if-else Statement

When you need to do one thing if true, and a different thing if false. One of the two blocks always executes — never both, never neither.

// if-else — Flow Diagram
JavaIfElse.java
int score = 45;

if (score >= 50) {
    System.out.println("PASS");
} else {
    System.out.println("FAIL");   // prints this (45 < 50)
}

// Selenium example: login result check
String pageTitle = "Dashboard";
String expected  = "Dashboard";

if (pageTitle.equals(expected)) {
    System.out.println("Login test PASSED ✓");
} else {
    System.out.println("Login test FAILED ✗ — Expected: "
                       + expected + " Got: " + pageTitle);
}
06

if-else if-else Chain

When you have more than two possible outcomes. Java checks each condition top to bottom and runs the first one that is true. Once a match is found, the rest are skipped.

JavaElseIfChain.java
int score = 72;

if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B");
} else if (score >= 70) {
    System.out.println("Grade: C");   // prints this (72 >= 70)
} else if (score >= 60) {
    System.out.println("Grade: D");
} else {
    System.out.println("Grade: F");
}

// Selenium use case: Browser selection in framework
String browser = "firefox";

if (browser.equals("chrome")) {
    System.out.println("Starting ChromeDriver");
} else if (browser.equals("firefox")) {
    System.out.println("Starting FirefoxDriver");  // prints
} else if (browser.equals("edge")) {
    System.out.println("Starting EdgeDriver");
} else {
    System.out.println("Browser not supported: " + browser);
}
✅
Always Put the Most Specific Condition First

In a chain, order matters. If you put score >= 50 first, it catches 72 and never reaches score >= 70. Always go from most specific (highest value) to least specific (lowest value).

07

Nested if

An if inside another if. Use when you need to check a secondary condition only after the primary one passes. Common in Selenium for element state validation.

JavaNestedIf.java
boolean isPageLoaded   = true;
boolean isUserLoggedIn = true;
boolean hasPermission  = false;

if (isPageLoaded) {
    System.out.println("Page loaded successfully");

    if (isUserLoggedIn) {
        System.out.println("User is logged in");

        if (hasPermission) {
            System.out.println("Access granted to admin panel");
        } else {
            System.out.println("No permission — redirect to home"); // prints
        }
    } else {
        System.out.println("Redirect to login page");
    }
} else {
    System.out.println("Page not loaded — test cannot proceed");
}
⚠️
Don't Nest More Than 3 Levels Deep

Deeply nested ifs become impossible to read and debug. If you find yourself at 4+ levels, refactor into methods. Clean code is a habit that matters in real QA jobs.

08

Ternary Operator

A shortcut for simple if-else on one line. Syntax: condition ? valueIfTrue : valueIfFalse

JavaTernary.java
int score = 75;

// Normal if-else
String result1;
if (score >= 50) {
    result1 = "PASS";
} else {
    result1 = "FAIL";
}

// Same thing with ternary — one line
String result2 = (score >= 50) ? "PASS" : "FAIL";

System.out.println(result2);  // PASS

// Selenium use: determine expected status in one line
boolean isDisplayed = true;
String status = isDisplayed ? "VISIBLE" : "HIDDEN";
System.out.println("Element is: " + status);  // Element is: VISIBLE
09

switch Statement

When you have one variable that could match several exact values, switch is cleaner than a long if-else if chain. It matches an exact value — no ranges, no complex conditions.

JavaSwitchDemo.java
String browser = "chrome";

switch (browser) {
    case "chrome":
        System.out.println("Launching Chrome browser");
        break;                    // MUST have break or it falls through!
    case "firefox":
        System.out.println("Launching Firefox browser");
        break;
    case "edge":
        System.out.println("Launching Edge browser");
        break;
    default:                      // runs if nothing matches
        System.out.println("Unknown browser: " + browser);
}
// Output: Launching Chrome browser

// What happens WITHOUT break? (fall-through bug)
int day = 2;
switch (day) {
    case 1: System.out.println("Monday");
    case 2: System.out.println("Tuesday");  // matches here...
    case 3: System.out.println("Wednesday"); // ...FALLS THROUGH here too!
    default: System.out.println("Other");    // ...and here!
}
// Bug output: Tuesday  Wednesday  Other  ← not what you wanted!
🚨
Never Forget break in switch

Without break, Java "falls through" — it keeps executing ALL cases below the match until it hits a break or the end. This is one of Java's most notorious beginner bugs.

for Loop

⏱ Hour 2 — Loops (60 mins)

Use for loop when you know exactly how many times to repeat something. The loop has 3 parts: initialization, condition, and update.

// for Loop — Anatomy & Flow
JavaForLoop.java
// Basic for loop — print 0 to 4
for (int i = 0; i < 5; i++) {
    System.out.println("Iteration: " + i);
}
// Output: 0, 1, 2, 3, 4

// Count from 1 to 10
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}

// Count DOWN
for (int i = 5; i > 0; i--) {
    System.out.println("Countdown: " + i);
}

// Step by 2
for (int i = 0; i <= 10; i += 2) {
    System.out.print(i + " ");    // 0 2 4 6 8 10
}

// Selenium: loop through test data
String[] testUsers = {"admin", "user1", "user2"};
for (int i = 0; i < testUsers.length; i++) {
    System.out.println("Testing login for: " + testUsers[i]);
}
// Output:
// Testing login for: admin
// Testing login for: user1
// Testing login for: user2
11

while Loop

Use while when you don't know in advance how many times to repeat. It checks the condition first — if false from the start, the body never runs.

// while vs do-while — Key Difference
JavaWhileLoop.java
// Basic while loop
int attempt = 1;
while (attempt <= 3) {
    System.out.println("Login attempt: " + attempt);
    attempt++;   // CRITICAL: always update variable or infinite loop!
}
// Output: Login attempt: 1  2  3

// Selenium: retry logic — keep retrying until element loads
int     retries    = 0;
int     maxRetries = 5;
boolean found      = false;

while (retries < maxRetries && !found) {
    System.out.println("Attempting to find element... try " + (retries + 1));
    // In real Selenium: try to find element here
    // Simulate: found on 3rd attempt
    if (retries == 2) {
        found = true;
    }
    retries++;
}

if (found) {
    System.out.println("Element found!");
} else {
    System.out.println("Element not found after " + maxRetries + " tries");
}
⚠️
Infinite Loop — The Most Common while Bug

If you forget to update the variable inside the loop (e.g., forget attempt++), the condition never becomes false, and your program freezes forever. IntelliJ will hang. Force-stop with the red stop button. Always double-check your update step.

12

do-while Loop

Like while but the body always runs at least once regardless of the condition. The check happens at the bottom, not the top.

JavaDoWhile.java
// do-while — runs at least once
int count = 0;
do {
    System.out.println("Executed: " + count);
    count++;
} while (count < 3);
// Output: 0, 1, 2

// Compare: even if condition is false from start, do-while runs once
int x = 10;

// while — does NOT run (10 < 5 is false)
while (x < 5) {
    System.out.println("while: never prints");
}

// do-while — runs ONCE even though 10 < 5 is false
do {
    System.out.println("do-while: prints once!"); // prints!
} while (x < 5);

// Selenium use: menu validation — open menu then check items
int menuItems = 0;
do {
    System.out.println("Checking menu item: " + menuItems);
    menuItems++;
} while (menuItems < 4);
13

Enhanced for Loop (for-each)

A cleaner way to loop through arrays or collections when you don't need the index. This is the most common loop you'll use with Selenium's findElements() which returns a list.

JavaForEach.java
// Syntax: for (type variable : array/list) { }

String[] browsers = {"Chrome", "Firefox", "Edge"};

// Regular for (needs index)
for (int i = 0; i < browsers.length; i++) {
    System.out.println(browsers[i]);
}

// for-each (cleaner, no index needed)
for (String browser : browsers) {
    System.out.println("Testing on: " + browser);
}
// Output: Chrome, Firefox, Edge

// Selenium real-world example:
// List<WebElement> links = driver.findElements(By.tagName("a"));
// for (WebElement link : links) {
//     System.out.println(link.getText());  ← prints text of each link
// }

// Another example: verify all nav menu items
String[] menuItems = {"Home", "Dashboard", "Reports", "Logout"};
String[] expected  = {"Home", "Dashboard", "Reports", "Logout"};

int idx = 0;
for (String item : menuItems) {
    if (item.equals(expected[idx])) {
        System.out.println("✓ " + item);
    } else {
        System.out.println("✗ Expected: " + expected[idx] + " Got: " + item);
    }
    idx++;
}
📌
Use for-each when you don't need the index. Use regular for when you do.

If you need to know the position (index 0, 1, 2...), use regular for. If you just need each element, use for-each. It's cleaner and less error-prone.

14

break & continue

break — Exit the loop entirely

Stops the loop immediately. Code after the loop continues. Use when you found what you need and don't need to keep looping.

continue — Skip current iteration

Skips the rest of the current loop body and goes to the next iteration. Use to skip certain elements without stopping the loop.

JavaBreakContinue.java
// BREAK: stop looping when target found
String[] users = {"alice", "bob", "sagar", "david"};
String target = "sagar";

for (String user : users) {
    System.out.println("Checking: " + user);
    if (user.equals(target)) {
        System.out.println("Found! Stopping search.");
        break;   // stop — no need to check david
    }
}
// Output: Checking: alice → bob → sagar → Found! Stopping search.

// CONTINUE: skip disabled users, process active ones
int[] userIds = {1, 2, 3, 4, 5};
int[] disabled = {2, 4};   // IDs 2 and 4 are disabled

for (int id : userIds) {
    if (id == 2 || id == 4) {
        System.out.println("Skipping disabled user: " + id);
        continue;  // skip this iteration, go to next id
    }
    System.out.println("Processing user: " + id);
}
// Output: 1(process) → 2(skip) → 3(process) → 4(skip) → 5(process)
15

Nested Loops

A loop inside another loop. The inner loop completes fully for each single iteration of the outer loop. Used in Selenium for table testing (rows × columns).

JavaNestedLoops.java
// Basic nested loop: multiplication table
for (int i = 1; i <= 3; i++) {          // outer: rows
    for (int j = 1; j <= 3; j++) {      // inner: columns
        System.out.print((i * j) + "\t");
    }
    System.out.println();               // new line after each row
}
// Output:
// 1   2   3
// 2   4   6
// 3   6   9

// Selenium use: verify data in an HTML table
String[][] tableData = {
    {"John", "Admin", "Active"},
    {"Jane", "User",  "Active"},
    {"Bob",  "User",  "Inactive"}
};

for (int row = 0; row < tableData.length; row++) {
    System.out.print("Row " + (row + 1) + ": ");
    for (int col = 0; col < tableData[row].length; col++) {
        System.out.print(tableData[row][col] + "  ");
    }
    System.out.println();
}
// Row 1: John  Admin  Active
// Row 2: Jane  User   Active
// Row 3: Bob   User   Inactive

Practice Task + Expected Output

Type all of this from scratch. This task uses every concept from today — if, else if, for, while, for-each, break, continue. Do not skip it.

JavaDay2Practice.java
public class Day2Practice {

    public static void main(String[] args) {

        System.out.println("====== TASK 1: Grade Checker ======");
        int[] scores = {92, 78, 65, 45, 55, 88};
        for (int score : scores) {
            String grade;
            if      (score >= 90) grade = "A";
            else if (score >= 80) grade = "B";
            else if (score >= 70) grade = "C";
            else if (score >= 50) grade = "D";
            else                   grade = "F";
            String result = (score >= 50) ? "PASS" : "FAIL";
            System.out.println("Score: " + score + " → Grade: "
                               + grade + " [" + result + "]");
        }

        System.out.println("\n====== TASK 2: Even/Odd 1-10 ======");
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                System.out.println(i + " → EVEN");
            } else {
                System.out.println(i + " → ODD");
            }
        }

        System.out.println("\n====== TASK 3: Find Target User ======");
        String[] users = {"alice", "bob", "sagar", "dave", "eve"};
        String targetUser = "sagar";
        boolean userFound = false;
        for (String user : users) {
            if (user.equals(targetUser)) {
                System.out.println("✓ Found: " + user);
                userFound = true;
                break;
            }
            System.out.println("  Checked: " + user);
        }
        if (!userFound) {
            System.out.println("User not found: " + targetUser);
        }

        System.out.println("\n====== TASK 4: Skip Inactive Users ======");
        String[] allUsers    = {"Admin", "User1", "Guest", "User2"};
        boolean[] isActive  = {true, false, false, true};
        for (int i = 0; i < allUsers.length; i++) {
            if (!isActive[i]) {
                System.out.println("  Skipped: " + allUsers[i] + " (inactive)");
                continue;
            }
            System.out.println("✓ Processing: " + allUsers[i]);
        }

        System.out.println("\n====== TASK 5: Login Retry ======");
        int loginAttempts = 0;
        int maxAttempts   = 3;
        boolean loggedIn  = false;
        while (loginAttempts < maxAttempts && !loggedIn) {
            loginAttempts++;
            System.out.println("Login attempt #" + loginAttempts);
            if (loginAttempts == 2) {  // simulate success on attempt 2
                loggedIn = true;
                System.out.println("Login SUCCESS on attempt " + loginAttempts);
            }
        }
        if (!loggedIn) {
            System.out.println("Login FAILED after " + maxAttempts + " attempts");
        }

        System.out.println("\n====== TASK 6: Browser Switch ======");
        String[] testBrowsers = {"chrome", "firefox", "safari"};
        for (String b : testBrowsers) {
            switch (b) {
                case "chrome":
                    System.out.println("→ ChromeDriver initialized"); break;
                case "firefox":
                    System.out.println("→ FirefoxDriver initialized"); break;
                default:
                    System.out.println("→ " + b + ": Not supported yet");
            }
        }
    }
}

Common Mistakes

❌ = instead of == in conditions

if (x = 5) assigns 5 to x and then evaluates x as boolean — compile error or wrong result. Always == inside conditions.

❌ Infinite while loop

Forgetting to update the variable inside while loop. Your program hangs. Always ask: "What makes this condition eventually false?"

❌ Missing break in switch

Without break, execution falls through to the next case. Always add break at the end of every case unless fall-through is intentional.

❌ Off-by-one in for loop

i < 10 runs 0–9 (10 times). i <= 10 runs 0–10 (11 times). Know the difference — wrong boundary skips or repeats data.

❌ Using == to compare Strings in if

if (browser == "chrome") may return false even when values match. Always browser.equals("chrome").

❌ Wrong condition order in if-else if

Putting score >= 50 before score >= 80 means 80 gets caught by the first condition. Always most specific first.

❌ Modifying array in for-each

You cannot change array elements inside a for-each loop — the loop variable is a copy, not a reference. Use regular for loop for modifications.

❌ Semicolon after for()

for (int i = 0; i < 5; i++); — that semicolon creates an empty loop body. The actual block below runs only once. Easy to miss.
