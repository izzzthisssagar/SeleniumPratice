Native Select — Select Class Deep Dive

JavaNativeSelect.java
import org.openqa.selenium.support.ui.Select;

// Always wrap the raw WebElement with Select
WebElement raw = driver.findElement(By.id("countryDropdown"));
Select select   = new Select(raw);

// 3 ways to select an option
select.selectByVisibleText("Nepal");   // text you see in UI — most readable
select.selectByValue("np");           // value= attribute — reliable
select.selectByIndex(2);             // zero-based index

// Read current selection
WebElement picked = select.getFirstSelectedOption();
System.out.println("Picked: " + picked.getText());
System.out.println("Value : " + picked.getAttribute("value"));

// Validate a specific option exists
boolean hasNepal = select.getOptions().stream()
    .anyMatch(o -> o.getText().equals("Nepal"));
System.out.println("Has Nepal: " + hasNepal);

// Print all options
System.out.println("All options:");
for (WebElement opt : select.getOptions()) {
    String marker = opt.isSelected() ? " ← selected" : "";
    System.out.println("  " + opt.getText() + marker);
}

// Verify dropdown has expected number of options
int optCount = select.getOptions().size();
System.out.println("Total options: " + optCount);

OrangeHRM Custom Dropdown Pattern

OrangeHRM uses Vue.js custom dropdowns — they look like dropdowns but use <div> elements, not <select>. The Select class won't work. Here's the full pattern.

JavaOrangeHRM_CustomDropdown.java
// OrangeHRM dropdown HTML structure:
// <div class="oxd-select-wrapper">
//   <div class="oxd-select-text-input">-- Select --</div>
//   <div class="oxd-select-dropdown"> (hidden until clicked)
//     <span class="oxd-select-option"><span>Admin</span></span>
//     <span class="oxd-select-option"><span>ESS</span></span>
//   </div>
// </div>

// STEP 1: Click the dropdown trigger to open it
WebElement dropdown = driver.findElement(
    By.xpath("//label[text()='User Role']/following::div[@class='oxd-select-text-input'][1]"));
dropdown.click();
Thread.sleep(500); // wait for options to appear

// STEP 2: Click the specific option
driver.findElement(
    By.xpath("//div[@class='oxd-select-dropdown']//span[text()='Admin']")).click();
System.out.println("Selected: Admin");

// Alternative: by option index
dropdown.click();
Thread.sleep(500);
List<WebElement> options = driver.findElements(
    By.cssSelector(".oxd-select-option span"));
System.out.println("Options found: " + options.size());
for (WebElement opt : options) {
    System.out.println("  " + opt.getText());
}
// Click first option
options.get(0).click();

// VERIFY selection shows in dropdown text
String selectedText = driver.findElement(
    By.cssSelector(".oxd-select-text-input")).getText();
System.out.println("Now shows: " + selectedText);

Auto-complete / Typeahead Dropdowns

Auto-complete fields show suggestions as you type. Type the text, wait for suggestions to appear, then click the right suggestion.

JavaAutoComplete.java
// PATTERN: type → wait for suggestions → click one

// Step 1: Find and type in the search field
WebElement searchField = driver.findElement(
    By.cssSelector(".oxd-autocomplete-text-input input"));
searchField.clear();
searchField.sendKeys("Adam");

// Step 2: Wait for suggestions dropdown to appear
Thread.sleep(1000); // temporary — use explicit wait on Day 20

// Step 3: Get all suggestions
List<WebElement> suggestions = driver.findElements(
    By.cssSelector(".oxd-autocomplete-dropdown .oxd-autocomplete-option"));
System.out.println("Suggestions: " + suggestions.size());

// Step 4: Click matching suggestion
for (WebElement sug : suggestions) {
    System.out.println("  Option: " + sug.getText());
    if (sug.getText().contains("Adam")) {
        sug.click();
        System.out.println("  Selected: " + sug.getText());
        break;
    }
}

// Verify selection in field
String selectedVal = searchField.getAttribute("value");
System.out.println("Field value: " + selectedVal);

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

LocalDate today     = LocalDate.now();
LocalDate tomorrow  = today.plusDays(1);
LocalDate nextMonth = today.plusMonths(1);
LocalDate lastYear  = today.minusYears(1);

DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd");
dateField.sendKeys(tomorrow.format(fmt));
System.out.println("Tomorrow: " + tomorrow.format(fmt));

Date Picker — Calendar Widget

OrangeHRM's date pickers open a calendar popup. You navigate to the right month/year and click the day. This requires more steps but follows a clear pattern.

JavaCalendarWidget.java
// OrangeHRM calendar structure:
// <div class="oxd-date-input">
//   <input type="text" readonly> ← display field
//   [calendar popup appears when clicked]
// </div>

// STEP 1: Click the date field to open calendar
WebElement dateInput = driver.findElement(
    By.cssSelector(".oxd-date-input input"));
dateInput.click();
Thread.sleep(500);

// STEP 2: Read current month/year shown
String currentMonth = driver.findElement(
    By.cssSelector(".oxd-calendar-selector-month-selected")).getText();
System.out.println("Calendar showing: " + currentMonth);

// STEP 3: Navigate months (click prev/next arrows)
WebElement prevBtn = driver.findElement(
    By.cssSelector(".oxd-calendar-selector-left button"));
WebElement nextBtn = driver.findElement(
    By.cssSelector(".oxd-calendar-selector-right button"));

// Navigate back 2 months
prevBtn.click(); Thread.sleep(300);
prevBtn.click(); Thread.sleep(300);

// STEP 4: Click specific day
List<WebElement> days = driver.findElements(
    By.cssSelector(".oxd-calendar-date:not(.oxd-calendar-date--disabled)"));
for (WebElement day : days) {
    if (day.getText().equals("15")) {
        day.click();
        System.out.println("Clicked day 15");
        break;
    }
}

// STEP 5: Verify date was set
String setDate = dateInput.getAttribute("value");
System.out.println("Date set to: " + setDate);

Date Picker — JavaScript Override

When a date input is readonly and the calendar is complex to navigate, use JavaScript to set the value directly. Faster but bypasses UI validation — use cautiously.

JavaDatePickerJS.java
JavascriptExecutor js = (JavascriptExecutor) driver;
WebElement dateInput = driver.findElement(By.cssSelector(".oxd-date-input input"));

// Method 1: Set value via JS (bypasses readonly)
js.executeScript("arguments[0].value = arguments[1]", dateInput, "2024-03-15");

// Method 2: Remove readonly attribute, then sendKeys
js.executeScript("arguments[0].removeAttribute('readonly')", dateInput);
dateInput.clear();
dateInput.sendKeys("03/15/2024");

// Method 3: Set via value property + trigger change event
js.executeScript(
    "arguments[0].value = '2024-03-15'; "
    + "arguments[0].dispatchEvent(new Event('change'))",
    dateInput);

// Verify
String val = dateInput.getAttribute("value");
System.out.println("Date value: " + val);

// For OrangeHRM specifically — sendKeys works after clearing:
dateInput.sendKeys(Keys.CONTROL, "a");
dateInput.sendKeys("03/15/2024"); // MM/DD/YYYY format for OrangeHRM
⚡
OrangeHRM date format is MM/DD/YYYY

OrangeHRM's date fields expect MM/DD/YYYY format, not ISO (YYYY-MM-DD). Always check the placeholder text in DevTools to confirm the expected format before typing a date.

Dynamic Elements — Elements That Appear After Action

Modern apps load content dynamically. After clicking a dropdown or button, new elements appear in the DOM. You must wait for them before interacting.

JavaDynamicElements.java
// PROBLEM: Element not in DOM yet — findElement throws NoSuchElementException

// Scenario 1: Options appear after clicking dropdown
driver.findElement(By.cssSelector(".dropdown-trigger")).click();
// If you immediately find options → NoSuchElementException
// Solution: small pause (temporary until Day 20 explicit waits)
Thread.sleep(500);
driver.findElement(By.cssSelector(".dropdown-option")).click();

// Scenario 2: Error message appears after clicking submit
driver.findElement(By.cssSelector("button[type='submit']")).click();
Thread.sleep(1000);
boolean hasError = !driver.findElements(
    By.cssSelector(".error-message")).isEmpty();

// Scenario 3: Table reloads after search filter

    By.cssSelector("tbody tr"));

Waiting for Dynamic Elements

⏰ Hour 2 — Dynamic Handling & Utilities (60 mins)
JavaWaitForElement.java
// TEMPORARY approach (Days 9-19): polling loop
// This is a manual explicit wait — replaced by WebDriverWait on Day 20

public static WebElement waitForElement(
        WebDriver driver, By locator, int maxSeconds) {
    int waited = 0;
    while (waited < maxSeconds * 1000) {
        List<WebElement> els = driver.findElements(locator);
        if (!els.isEmpty() && els.get(0).isDisplayed()) {
            return els.get(0);
        }
        try { Thread.sleep(500); } catch (InterruptedException e) { break; }
        waited += 500;
    }
    throw new RuntimeException("Element not found after " + maxSeconds + "s: " + locator);
}

// Wait for dropdown options to appear
public static List<WebElement> waitForOptions(
        WebDriver driver, By optionLocator, int maxSeconds) {
    int waited = 0;
    while (waited < maxSeconds * 1000) {
        List<WebElement> opts = driver.findElements(optionLocator);
        if (!opts.isEmpty()) return opts;
        try { Thread.sleep(300); } catch (InterruptedException e) { break; }
        waited += 300;
    }
    throw new RuntimeException("Options not found: " + optionLocator);
}

// Usage
driver.findElement(By.cssSelector(".dropdown")).click();
List<WebElement> opts = waitForOptions(driver,
    By.cssSelector(".dropdown-option"), 5);
System.out.println("Options: " + opts.size());
opts.get(0).click();
📌
Day 20 replaces all of this with WebDriverWait

The manual polling loop above is for learning purposes only. On Day 20 you'll replace every Thread.sleep and manual loop with new WebDriverWait(driver, Duration.ofSeconds(10)).until(ExpectedConditions.visibilityOfElementLocated(locator)) — one clean line that's faster and more reliable.

DropdownHelper Utility

JavaDropdownHelper.java — utils/DropdownHelper.java
package com.qaautomation.utils;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.Select;
import java.util.List;

public class DropdownHelper {

    // Native select — by visible text
    public static void selectByText(WebDriver d, By loc, String text) {
        new Select(d.findElement(loc)).selectByVisibleText(text);
    }

    // Native select — by value
    public static void selectByValue(WebDriver d, By loc, String value) {
        new Select(d.findElement(loc)).selectByValue(value);
    }

    // Get selected option text from native select
    public static String getSelectedText(WebDriver d, By loc) {
        return new Select(d.findElement(loc))
            .getFirstSelectedOption().getText();
    }

    // Custom dropdown — click trigger then click option by text
    public static void selectCustom(WebDriver d,
            By triggerLoc, By optionLoc, String text) {
        d.findElement(triggerLoc).click();
        BrowserUtils.pause(500);
        List<WebElement> opts = d.findElements(optionLoc);
        for (WebElement opt : opts) {
            if (opt.getText().trim().equals(text)) {
                opt.click();
                return;
            }
        }
        throw new RuntimeException("Option not found: " + text);
    }

    // Auto-complete — type and select suggestion
    public static void selectAutoComplete(WebDriver d,
            By inputLoc, By sugLoc, String typeText, String selectText) {
        WebElement input = d.findElement(inputLoc);
        input.clear();
        input.sendKeys(typeText);
        BrowserUtils.pause(1000);
        List<WebElement> sugs = d.findElements(sugLoc);
        for (WebElement sug : sugs) {
            if (sug.getText().contains(selectText)) {
                sug.click();
                return;
            }
        }
        throw new RuntimeException("Suggestion not found: " + selectText);
    }

    // Get all option texts from native select
    public static List<String> getAllOptionTexts(WebDriver d, By loc) {
        List<String> texts = new java.util.ArrayList<>();
        new Select(d.findElement(loc)).getOptions()
            .forEach(o -> texts.add(o.getText()));
        return texts;
    }
}

package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.Select;
import java.util.List;

public class Day18Practice {

    static final By USERNAME  = By.name("username");
    static final By PASSWORD  = By.name("password");
    static final By LOGIN_BTN = By.cssSelector("button[type='submit']");

    public static void main(String[] args) throws InterruptedException {
        WebDriver driver = DriverFactory.getDriver("chrome");

        try {
            // Login first
            driver.get(ConfigReader.getBaseUrl());
            driver.findElement(USERNAME).sendKeys(ConfigReader.getUsername());
            driver.findElement(PASSWORD).sendKeys(ConfigReader.getPassword());
            driver.findElement(LOGIN_BTN).click();
            Thread.sleep(2000);

            // Task 1: Navigate to Leave module
            System.out.println("====== TASK 1: Navigate to Leave ======");
            driver.findElement(By.xpath("//span[text()='Leave']")).click();
            Thread.sleep(1500);
            System.out.println("  Page: " + driver.getTitle());
            System.out.println("  URL : " + driver.getCurrentUrl());

            // Task 2: Explore the Leave List page
            System.out.println("\n====== TASK 2: Leave List Elements ======");
            boolean hasTable = !driver.findElements(
                By.cssSelector(".oxd-table")).isEmpty();
            System.out.println("  Has table: " + hasTable);

            boolean hasFilter = !driver.findElements(
                By.cssSelector(".oxd-form")).isEmpty();
            System.out.println("  Has filter form: " + hasFilter);

            // Task 3: Check dropdown elements on the page
            System.out.println("\n====== TASK 3: Dropdowns ======");
            List<WebElement> selects = driver.findElements(
                By.cssSelector(".oxd-select-wrapper"));
            System.out.println("  Custom dropdowns on page: " + selects.size());

            List<WebElement> inputs = driver.findElements(
                By.cssSelector(".oxd-date-input input"));
            System.out.println("  Date fields on page: " + inputs.size());

            // Task 4: Set date fields if present
            System.out.println("\n====== TASK 4: Date Fields ======");
            if (!inputs.isEmpty()) {
                WebElement firstDate = inputs.get(0);
                System.out.println("  1st date field visible: " + firstDate.isDisplayed());
                System.out.println("  Placeholder: " + firstDate.getAttribute("placeholder"));
                firstDate.clear();
                firstDate.sendKeys("01/01/2024");
                Thread.sleep(300);
                System.out.println("  Date typed: 01/01/2024");
            } else {
                System.out.println("  No date fields visible (might need to open Leave form)");
            }

            // Task 5: Search button state
            System.out.println("\n====== TASK 5: Buttons ======");
            List<WebElement> buttons = driver.findElements(
                By.cssSelector("button.oxd-button"));
            System.out.println("  Buttons on page: " + buttons.size());
            for (WebElement b : buttons) {
                System.out.println("  → '" + b.getText() + "' enabled=" + b.isEnabled());
            }
            System.out.println("  ✓ PASS");

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ Using Select on custom dropdown

If the HTML is <div> not <select>, new Select(element) throws UnexpectedTagNameException. Always inspect the HTML tag before choosing your strategy.

❌ Not waiting after dropdown click

Clicking the dropdown trigger and immediately finding options — the options haven't rendered yet. Add Thread.sleep(500) or Day 20's explicit wait.

❌ Wrong date format

OrangeHRM uses MM/DD/YYYY. HTML5 date inputs use YYYY-MM-DD. Bootstrap datepickers may use DD/MM/YYYY. Always check the placeholder in DevTools.

❌ Typing in read-only date field

sendKeys on a readonly input silently fails. Use JS to remove readonly first, or use the calendar widget to navigate and click the day.

❌ Auto-complete not waiting for suggestions

Type text, then immediately look for suggestions — they haven't loaded. The search hits an API. Wait 1+ seconds after sendKeys before finding suggestion elements.

❌ Clicking disabled option

Some dropdown options are disabled (grayed out). Clicking them silently does nothing. Check isEnabled() or look for disabled CSS classes before clicking.
