Why This Day Changes Everything

⏰ Hour 1 — Explicit Wait Fundamentals (60 mins)

Every Thread.sleep(2000) in your code is a lie — you're guessing that 2 seconds is enough. Sometimes it's too short (flaky test). Sometimes it's too long (slow suite). Explicit waits solve both problems: they wait exactly as long as needed — no more, no less.

🌟
The transformation from junior to senior QA automation engineer

Junior: uses Thread.sleep everywhere → tests take 10 minutes, fail randomly.
Senior: uses explicit waits everywhere → tests take 3 minutes, pass consistently.
After today, you write senior-level wait code. Every Thread.sleep you had from Days 11–19 gets deleted.

WebDriverWait — Syntax & How It Works

JavaWebDriverWait_Syntax.java
import org.openqa.selenium.support.ui.WebDriverWait;
import org.openqa.selenium.support.ui.ExpectedConditions;
import java.time.Duration;

// Create wait object — max wait = 10 seconds
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

// Wait until element is visible, then return it
WebElement element = wait.until(
    ExpectedConditions.visibilityOfElementLocated(By.name("username")));

// How it works internally:
// 1. Checks condition immediately
// 2. If true → returns result immediately
// 3. If false → waits 500ms, checks again
// 4. Repeats until timeout (10s) or condition met
// 5. If 10s passes without condition → TimeoutException

// Basic pattern every time:
WebDriverWait wait10 = new WebDriverWait(driver, Duration.ofSeconds(10));
WebDriverWait wait5  = new WebDriverWait(driver, Duration.ofSeconds(5));
WebDriverWait wait30 = new WebDriverWait(driver, Duration.ofSeconds(30));

// Use shorter waits for fast operations, longer for page loads
// 5-10s: element appearance after click
// 10-15s: page navigation
// 30s: file upload, PDF generation
04

ExpectedConditions — Full Reference

visibilityOfElementLocated(By)

Wait until element exists in DOM AND is visible. Returns WebElement. Most used condition.

elementToBeClickable(By)

Wait until element is visible AND enabled. Use before click() or sendKeys().

presenceOfElementLocated(By)

Wait until element exists in DOM — may not be visible. Faster than visibility check.

invisibilityOfElementLocated(By)

Wait until element is gone or hidden. Use for loading spinners.

textToBePresentInElement(el, text)

Wait until element's text contains the specified string.

urlContains(text)

Wait until current URL contains the text. Use after navigation.

urlToBe(fullUrl)

Wait until URL exactly matches. Strict version of urlContains.

titleContains(text)

Wait until page title contains the text.

alertIsPresent()

Wait until a JavaScript alert appears.

frameToBeAvailable(nameOrId)

Wait until iframe is available and switch into it.

numberOfWindowsToBe(n)

Wait until n browser tabs/windows are open.

stalenessOf(element)

Wait until element becomes stale (page refreshed). Use before re-finding.

Visibility Conditions

JavaVisibilityConditions.java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

// ── visibilityOfElementLocated — by locator ───────────────────
// Waits for element to be in DOM AND visible
WebElement userField = wait.until(
    ExpectedConditions.visibilityOfElementLocated(By.name("username")));
userField.sendKeys("Admin");

// ── visibilityOf — by WebElement reference ────────────────────
WebElement raw = driver.findElement(By.name("username"));
WebElement visible = wait.until(ExpectedConditions.visibilityOf(raw));

// ── visibilityOfAllElementsLocatedBy — list ───────────────────
List<WebElement> rows = wait.until(
    ExpectedConditions.visibilityOfAllElementsLocatedBy(
        By.cssSelector("tbody tr")));
System.out.println("Rows loaded: " + rows.size());

// ── presenceOfElementLocated — in DOM (may be hidden) ─────────
WebElement hiddenEl = wait.until(
    ExpectedConditions.presenceOfElementLocated(By.id("hiddenInput")));

// ── invisibilityOfElementLocated — element disappears ─────────
// Wait for loading spinner to disappear
wait.until(ExpectedConditions.invisibilityOfElementLocated(
    By.cssSelector(".loading-spinner")));
System.out.println("Loading complete");

// ── numberOfElementsToBeMoreThan — wait for list to load ──────
wait.until(ExpectedConditions.numberOfElementsToBeMoreThan(
    By.cssSelector("tbody tr"), 0)); // at least 1 row

Clickability & Element State

JavaClickabilityConditions.java
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

// ── elementToBeClickable — visible AND enabled ────────────────
// THE most used condition for buttons and links
WebElement loginBtn = wait.until(
    ExpectedConditions.elementToBeClickable(
        By.cssSelector("button[type='submit']")));
loginBtn.click();

// Also works with existing WebElement reference
WebElement btn = driver.findElement(By.id("submitBtn"));
wait.until(ExpectedConditions.elementToBeClickable(btn)).click();

// ── elementToBeSelected — for checkboxes/radios ───────────────
wait.until(ExpectedConditions.elementToBeSelected(
    driver.findElement(By.id("checkboxId"))));

// ── elementSelectionStateToBe — check/uncheck state ──────────
wait.until(ExpectedConditions.elementSelectionStateToBe(
    driver.findElement(By.id("myCheckbox")), true));  // wait until checked

// ── textToBePresentInElement ──────────────────────────────────
WebElement errorMsg = driver.findElement(By.cssSelector(".error"));
wait.until(ExpectedConditions.textToBePresentInElement(errorMsg, "Invalid"));
System.out.println("Error text: " + errorMsg.getText());

// ── attributeContains — wait for attribute change ─────────────
wait.until(ExpectedConditions.attributeContains(
    By.id("statusBadge"), "class", "active")); // class contains "active"

// ── attributeToBe — exact attribute value ─────────────────────
wait.until(ExpectedConditions.attributeToBe(
    By.id("input1"), "value", "Expected"));

Custom ExpectedConditions

JavaCustomConditions.java
import org.openqa.selenium.support.ui.ExpectedCondition;

// ExpectedCondition is a functional interface — implement with lambda

// Custom: wait until element has specific text
ExpectedCondition<WebElement> hasText = d -> {
    WebElement el = d.findElement(By.cssSelector(".status"));
    return el.getText().contains("Active") ? el : null;
};
WebElement statusEl = wait.until(hasText);

// Custom: wait until table has at least N rows
ExpectedCondition<Boolean> hasRows = d -> {
    List<WebElement> rows = d.findElements(By.cssSelector("tbody tr"));
    return rows.size() >= 5;
};
wait.until(hasRows);

// Custom: wait until page is fully loaded (readyState)
ExpectedCondition<Boolean> pageReady = d ->
    ((JavascriptExecutor) d)
        .executeScript("return document.readyState")
        .equals("complete");
wait.until(pageReady);
System.out.println("Page fully loaded");

// Custom: wait until dropdown has options
ExpectedCondition<List<WebElement>> hasOptions = d -> {
    List<WebElement> opts = d.findElements(
        By.cssSelector(".dropdown-option"));
    return opts.isEmpty() ? null : opts;
};
List<WebElement> options = wait.until(hasOptions);

FluentWait — Advanced Configuration

⏰ Hour 2 — FluentWait, WaitUtils & Practice (60 mins)
JavaFluentWait.java
import org.openqa.selenium.support.ui.FluentWait;
import java.time.Duration;

// FluentWait gives you control over:
// - Max wait time
// - Polling interval (how often to check)
// - Which exceptions to ignore while waiting

FluentWait<WebDriver> fluentWait = new FluentWait<>(driver)
    .withTimeout(Duration.ofSeconds(20))        // max wait
    .pollingEvery(Duration.ofMillis(500))        // check every 500ms
    .ignoring(NoSuchElementException.class)     // ignore NoSuchElement while waiting
    .ignoring(StaleElementReferenceException.class); // ignore stale while waiting

// Use it with ExpectedConditions
WebElement element = fluentWait.until(
    ExpectedConditions.visibilityOfElementLocated(By.name("username")));

// Or with custom lambda
WebElement el = fluentWait.until(d ->
    d.findElement(By.cssSelector(".oxd-input")));

// FluentWait vs WebDriverWait
// WebDriverWait IS a FluentWait with 500ms polling and NoSuchElement ignored
// Use WebDriverWait for 95% of cases
// Use FluentWait when you need custom polling interval or additional ignored exceptions

// Fast polling for quick animations
FluentWait<WebDriver> fastWait = new FluentWait<>(driver)
    .withTimeout(Duration.ofSeconds(5))
    .pollingEvery(Duration.ofMillis(100))  // check every 100ms
    .ignoring(NoSuchElementException.class);

WaitUtils — Reusable Wait Helper

JavaWaitUtils.java — utils/WaitUtils.java
package com.qaautomation.utils;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;
import java.time.Duration;
import java.util.List;

public class WaitUtils {

    private static final int DEFAULT_TIMEOUT = 10;

    private static WebDriverWait getWait(WebDriver driver, int sec) {
        return new WebDriverWait(driver, Duration.ofSeconds(sec));
    }

    // Wait for element to be visible
    public static WebElement waitVisible(WebDriver d, By loc) {
        return getWait(d, DEFAULT_TIMEOUT).until(
            ExpectedConditions.visibilityOfElementLocated(loc));
    }

    // Wait for element to be clickable
    public static WebElement waitClickable(WebDriver d, By loc) {
        return getWait(d, DEFAULT_TIMEOUT).until(
            ExpectedConditions.elementToBeClickable(loc));
    }

    // Wait + click in one call
    public static void waitAndClick(WebDriver d, By loc) {
        waitClickable(d, loc).click();
    }

    // Wait + type in one call
    public static void waitAndType(WebDriver d, By loc, String text) {
        WebElement el = waitVisible(d, loc);
        el.clear();
        el.sendKeys(text);
    }

    // Wait for URL
    public static void waitForUrl(WebDriver d, String urlPart) {
        getWait(d, 15).until(ExpectedConditions.urlContains(urlPart));
    }

    // Wait for title
    public static void waitForTitle(WebDriver d, String title) {
        getWait(d, 10).until(ExpectedConditions.titleContains(title));
    }

    // Wait for element to disappear
    public static void waitInvisible(WebDriver d, By loc) {
        getWait(d, DEFAULT_TIMEOUT).until(
            ExpectedConditions.invisibilityOfElementLocated(loc));
    }

    // Wait for list of elements
    public static List<WebElement> waitAllVisible(WebDriver d, By loc) {
        return getWait(d, DEFAULT_TIMEOUT).until(
            ExpectedConditions.visibilityOfAllElementsLocatedBy(loc));
    }

    // Wait for text in element
    public static void waitForText(WebDriver d, By loc, String text) {
        getWait(d, DEFAULT_TIMEOUT).until(
            ExpectedConditions.textToBePresentInElementLocated(loc, text));
    }

    // Is element present (no exception)
    public static boolean isPresent(WebDriver d, By loc) {
        try {
            getWait(d, 3).until(ExpectedConditions.presenceOfElementLocated(loc));
            return true;
        } catch (TimeoutException e) {
            return false;
        }
    }
}

Updated BaseTest with Waits

JavaBaseTest.java — Updated with WaitUtils
package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;
import java.time.Duration;

public class BaseTest {

    protected WebDriver       driver;
    protected WebDriverWait   wait;
    protected String          browser = ConfigReader.getBrowser();

    public void setUp() {
        driver = DriverFactory.getDriver(browser);
        wait   = new WebDriverWait(driver, Duration.ofSeconds(10));
        System.out.println("[SETUP] " + browser + " started");
    }

    public void tearDown() {
        if (driver != null) {
            driver.quit();
            System.out.println("[QUIT] Browser closed");
        }
    }

    // Helper: wait + click
    protected void click(By locator) {
        wait.until(ExpectedConditions.elementToBeClickable(locator)).click();
    }

    // Helper: wait + type
    protected void type(By locator, String text) {
        WebElement el = wait.until(
            ExpectedConditions.visibilityOfElementLocated(locator));
        el.clear();
        el.sendKeys(text);
    }

    // Helper: wait + getText
    protected String getText(By locator) {
        return wait.until(
            ExpectedConditions.visibilityOfElementLocated(locator)).getText();
    }

    // Helper: wait for URL
    protected void waitForUrl(String urlPart) {
        new WebDriverWait(driver, Duration.ofSeconds(15))
            .until(ExpectedConditions.urlContains(urlPart));
    }
}

Practice Task — Full Login Script With Explicit Waits

JavaDay20Practice.java — NO Thread.sleep anywhere
package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;
import java.time.Duration;

public class Day20Practice {

    static final By USERNAME   = By.name("username");
    static final By PASSWORD   = By.name("password");
    static final By LOGIN_BTN  = By.cssSelector("button[type='submit']");
    static final By ERROR_MSG  = By.cssSelector(".oxd-alert-content");
    static final By USER_NAME  = By.cssSelector(".oxd-userdropdown-name");
    static final By DASHBOARD  = By.xpath("//h6[text()='Dashboard']");

    public static void main(String[] args) {
        WebDriver     driver = DriverFactory.getDriver("chrome");
        WebDriverWait wait   = new WebDriverWait(driver, Duration.ofSeconds(10));

        try {
            driver.get(ConfigReader.getBaseUrl());

            // Task 1: Valid login with explicit waits (no sleep!)
            System.out.println("====== TASK 1: Valid Login (Explicit Waits) ======");
            WaitUtils.waitAndType(driver, USERNAME, ConfigReader.getUsername());
            WaitUtils.waitAndType(driver, PASSWORD, ConfigReader.getPassword());
            WaitUtils.waitAndClick(driver, LOGIN_BTN);
            WaitUtils.waitForUrl(driver, "dashboard");

            String loggedUser = WaitUtils.waitVisible(driver, USER_NAME).getText();
            boolean dashVis   = WaitUtils.isPresent(driver, DASHBOARD);
            System.out.println("  Logged in as  : " + loggedUser);
            System.out.println("  Dashboard shown: " + dashVis);
            System.out.println(dashVis ? "  ✓ PASS" : "  ✗ FAIL");

            // Task 2: Invalid login — wait for error message
            System.out.println("\n====== TASK 2: Invalid Login ======");
            driver.get(ConfigReader.getBaseUrl());
            WaitUtils.waitAndType(driver, USERNAME, "invalid_user");
            WaitUtils.waitAndType(driver, PASSWORD, "wrong_pass");
            WaitUtils.waitAndClick(driver, LOGIN_BTN);
            // Wait for error message to appear
            WaitUtils.waitForText(driver, ERROR_MSG, "Invalid");
            String errText = WaitUtils.waitVisible(driver, ERROR_MSG).getText();
            System.out.println("  Error message: " + errText);
            System.out.println(errText.contains("Invalid") ? "  ✓ PASS" : "  ✗ FAIL");

            // Task 3: WebDriverWait directly
            System.out.println("\n====== TASK 3: Direct WebDriverWait ======");
            driver.get(ConfigReader.getBaseUrl());
            // Chain: wait visible → sendKeys
            wait.until(ExpectedConditions.visibilityOfElementLocated(USERNAME))
                .sendKeys(ConfigReader.getUsername());
            wait.until(ExpectedConditions.visibilityOfElementLocated(PASSWORD))
                .sendKeys(ConfigReader.getPassword());
            wait.until(ExpectedConditions.elementToBeClickable(LOGIN_BTN))
                .click();
            wait.until(ExpectedConditions.urlContains("dashboard"));
            System.out.println("  URL: " + driver.getCurrentUrl());
            System.out.println("  ✓ PASS");

            // Task 4: isPresent helper
            System.out.println("\n====== TASK 4: isPresent ======");
            System.out.println("  Dashboard heading present: "
                + WaitUtils.isPresent(driver, DASHBOARD));
            System.out.println("  Error msg present       : "
                + WaitUtils.isPresent(driver, ERROR_MSG));
            System.out.println("  ✓ PASS");

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ Mixing implicit + explicit waits

Having both driver.manage().timeouts().implicitlyWait(10) AND new WebDriverWait in the same script causes compounding timeouts. Use ONLY explicit waits (or only implicit as global safety). Never both.

❌ Creating WebDriverWait in every method

Creating new WebDriverWait(driver, Duration.ofSeconds(10)) in every test method is wasteful. Create it once in setUp() or use WaitUtils. One wait object per driver instance.

❌ visibilityOf vs elementToBeClickable

visibilityOf — element is visible but may be disabled. elementToBeClickable — visible AND enabled. Always use clickable before click(). Use visible for sendKeys and getText.

❌ Not handling TimeoutException

When WebDriverWait times out, it throws TimeoutException. Wrap waits in try-catch if the element's absence is a valid test scenario, not just an error.

❌ Waits on non-existent elements

If the element NEVER appears (wrong locator), the wait always times out after max timeout. Fix your locator first — don't increase the timeout.

❌ Still using Thread.sleep with waits

After implementing explicit waits, still leaving Thread.sleep calls from before. Do a project-wide search for "Thread.sleep" and delete every occurrence. Replace with the appropriate wait condition.
