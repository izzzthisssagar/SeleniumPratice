Browser Navigation — Full Reference

JavaNavigation_FullRef.java
import java.time.Duration;

// ── URL Loading ───────────────────────────────────────────────
driver.get("https://site.com");             // loads URL, waits for page
driver.navigate().to("https://site.com"); // same result

// ── History ───────────────────────────────────────────────────
driver.navigate().back();      // go back one page
driver.navigate().forward(); // go forward one page
driver.navigate().refresh(); // reload current page

// ── Get Page Info ────────────────────────────────────────────
String title  = driver.getTitle();           // text in browser tab
String url    = driver.getCurrentUrl();      // full URL with query params
String source = driver.getPageSource();     // full page HTML string

// ── Window Management ────────────────────────────────────────
driver.manage().window().maximize();
driver.manage().window().minimize();
driver.manage().window().fullscreen();
driver.manage().window().setSize(new Dimension(1920, 1080));

// ── Close vs Quit ─────────────────────────────────────────────
driver.close();  // closes CURRENT TAB only — driver still running
driver.quit();   // closes ALL TABS + kills driver process

// ── Timeouts (reminder) ───────────────────────────────────────
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
driver.manage().timeouts().pageLoadTimeout(Duration.ofSeconds(30));

Window Handles — Managing Multiple Tabs

Every browser tab has a unique window handle — a random string ID like CDwindow-4321ABCD. When a new tab opens, you must switch to it before interacting with its content. Selenium doesn't auto-switch.

// Window Handle Flow — Tab 1 opens Tab 2
JavaWindowHandles.java
import java.util.Set;
import java.util.ArrayList;

// Get current (main) tab handle — save it to return later
String mainTab = driver.getWindowHandle();
System.out.println("Main tab: " + mainTab);

// Perform action that opens new tab (e.g., click link with target="_blank")
// driver.findElement(By.linkText("Click here")).click();
// Or open new tab via JavaScript (see Section 4)

// Get ALL open tab handles
Set<String> allHandles = driver.getWindowHandles();
System.out.println("Total tabs: " + allHandles.size());

// Switch to NEW tab (the one that isn't the main tab)
for (String handle : allHandles) {
    if (!handle.equals(mainTab)) {
        driver.switchTo().window(handle);
        break;
    }
}
System.out.println("New tab title: " + driver.getTitle());

// Do work on new tab...
// driver.findElement(...).click();

// Close new tab and go back to main tab
driver.close();                          // close current (new) tab
driver.switchTo().window(mainTab);      // switch back to main tab
System.out.println("Back to: " + driver.getTitle());

Opening & Switching New Tabs

JavaOpenNewTab.java
// Method 1: Selenium 4 native new tab (recommended)
driver.switchTo().newWindow(WindowType.TAB);
driver.get("https://www.google.com");
System.out.println("New tab: " + driver.getTitle());

// Method 2: JavaScript to open new tab (works in all Selenium versions)
((JavascriptExecutor) driver).executeScript("window.open(arguments[0])",
    "https://www.google.com");

// After JS open — switch to newest tab
ArrayList<String> tabs = new ArrayList<>(driver.getWindowHandles());
driver.switchTo().window(tabs.get(tabs.size() - 1)); // last = newest
System.out.println("Switched to: " + driver.getTitle());

// Method 3: Selenium 4 new window (separate browser window)
driver.switchTo().newWindow(WindowType.WINDOW);
driver.get("https://demoqa.com");

// Helper method — switch to tab by its title
public static boolean switchToTabByTitle(WebDriver driver, String title) {
    for (String handle : driver.getWindowHandles()) {
        driver.switchTo().window(handle);
        if (driver.getTitle().contains(title)) {
            return true;
        }
    }
    return false;  // tab not found
}

Closing Specific Tabs

JavaCloseTabs.java
// Scenario: 3 tabs open, close the middle one, stay on main

String mainTab = driver.getWindowHandle();

// Open 2 more tabs
driver.switchTo().newWindow(WindowType.TAB);
driver.get("https://www.google.com");
String googleTab = driver.getWindowHandle();

driver.switchTo().newWindow(WindowType.TAB);
driver.get("https://demoqa.com");

System.out.println("Total tabs: " + driver.getWindowHandles().size()); // 3

// Switch to Google tab and close it
driver.switchTo().window(googleTab);
driver.close();  // closes Google tab only

// After closing a tab, switch to another — driver is in limbo
driver.switchTo().window(mainTab);  // MUST switch after close()
System.out.println("Total tabs now: " + driver.getWindowHandles().size()); // 2
System.out.println("Current: " + driver.getTitle());
🚨
Always switchTo() after driver.close()

After driver.close(), the driver has no active tab. Any command throws NoSuchWindowException. You MUST immediately driver.switchTo().window(someHandle) to a surviving tab before doing anything else.

Page Load Strategy

Page Load Strategy controls when driver.get() returns after navigation. It's set via ChromeOptions and affects how fast your tests run vs how stable they are.

StrategyWhen driver.get() ReturnsSpeedUse When
normal (default)When document.readyState = "complete" (all resources loaded)Slowest but safestAlways start with this
eagerWhen document.readyState = "interactive" (DOM ready, resources still loading)FasterPages with heavy images/ads you don't need
noneImmediately after initial request sentFastestOnly if you manage all waits manually
JavaPageLoadStrategy.java
import org.openqa.selenium.PageLoadStrategy;

// Set page load strategy via ChromeOptions
ChromeOptions options = new ChromeOptions();
options.setPageLoadStrategy(PageLoadStrategy.NORMAL);  // default — use this
// options.setPageLoadStrategy(PageLoadStrategy.EAGER);    // faster
// options.setPageLoadStrategy(PageLoadStrategy.NONE);     // manual waits only

WebDriverManager.chromedriver().setup();
WebDriver driver = new ChromeDriver(options);

// Check current page load state via JavaScript
String readyState = ((JavascriptExecutor) driver)
    .executeScript("return document.readyState")
    .toString();
System.out.println("Page state: " + readyState); // "complete"

JavaScript Executor — Basics

JavascriptExecutor lets you run raw JavaScript in the browser context. Use it when Selenium's standard methods can't reach an element, or when you need browser-level operations like scrolling.

JavaJavaScriptExecutor.java
import org.openqa.selenium.JavascriptExecutor;

// Cast driver to JavascriptExecutor
JavascriptExecutor js = (JavascriptExecutor) driver;

// ── Scroll Operations ─────────────────────────────────────────
// Scroll to bottom of page
js.executeScript("window.scrollTo(0, document.body.scrollHeight)");

// Scroll to top
js.executeScript("window.scrollTo(0, 0)");

// Scroll to specific element
WebElement element = driver.findElement(By.id("footer"));
js.executeScript("arguments[0].scrollIntoView(true)", element);

// Scroll by pixels
js.executeScript("window.scrollBy(0, 500)"); // down 500px

// ── Click via JS (when normal click fails) ────────────────────
WebElement btn = driver.findElement(By.id("hiddenBtn"));
js.executeScript("arguments[0].click()", btn);

// ── Type via JS ───────────────────────────────────────────────
WebElement input = driver.findElement(By.id("username"));
js.executeScript("arguments[0].value = arguments[1]", input, "Admin");

// ── Read values ───────────────────────────────────────────────
String title = (String) js.executeScript("return document.title");
String url   = (String) js.executeScript("return window.location.href");
Long height  = (Long)   js.executeScript("return document.body.scrollHeight");

System.out.println("Title : " + title);
System.out.println("URL   : " + url);
System.out.println("Height: " + height);

// ── Highlight element (useful for debugging) ──────────────────
public static void highlight(WebDriver driver, WebElement el) {
    (JavascriptExecutor) driver).executeScript(
        "arguments[0].style.border='3px solid red'", el);
}

Browser Logs

JavaBrowserLogs.java
import org.openqa.selenium.logging.*;
import java.util.logging.Level;

// Enable logging in ChromeOptions (must be done before driver creation)
ChromeOptions options = new ChromeOptions();
LoggingPreferences logPrefs = new LoggingPreferences();
logPrefs.enable(LogType.BROWSER, Level.ALL);
options.setCapability("goog:loggingPrefs", logPrefs);

WebDriver driver = new ChromeDriver(options);
driver.get("https://opensource-demo.orangehrmlive.com");

// Read browser console logs
LogEntries logs = driver.manage().logs().get(LogType.BROWSER);
System.out.println("Browser console logs: " + logs.getAll().size());

for (LogEntry entry : logs.getAll()) {
    System.out.printf("  [%s] %s%n",
        entry.getLevel(), entry.getMessage());
}

BrowserUtils — Reusable Utility Class

⏰ Hour 2 — BrowserUtils & Full Script (60 mins)

Stop copy-pasting the same code in every test. Put common operations in a BrowserUtils class. Every test calls these one-liners instead of repeating 4–5 lines of boilerplate.

JavaBrowserUtils.java — utils/BrowserUtils.java
package com.qaautomation.utils;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;
import java.time.Duration;
import java.util.*;

public class BrowserUtils {

    // ── Navigation ────────────────────────────────────────────
    public static void navigateTo(WebDriver driver, String url) {
        driver.get(url);
    }

    public static String getTitle(WebDriver driver) {
        return driver.getTitle();
    }

    public static String getCurrentUrl(WebDriver driver) {
        return driver.getCurrentUrl();
    }

    // ── Tab Management ────────────────────────────────────────
    public static String getMainTab(WebDriver driver) {
        return driver.getWindowHandle();
    }

    public static void switchToNewTab(WebDriver driver, String mainTab) {
        for (String h : driver.getWindowHandles()) {
            if (!h.equals(mainTab)) {
                driver.switchTo().window(h);
                return;
            }
        }
        throw new RuntimeException("No new tab found");
    }

    public static void switchToTabByTitle(WebDriver driver, String title) {
        for (String h : driver.getWindowHandles()) {
            driver.switchTo().window(h);
            if (driver.getTitle().contains(title)) return;
        }
        throw new RuntimeException("Tab not found: " + title);
    }

    public static void closeCurrentAndSwitch(WebDriver driver, String switchTo) {
        driver.close();
        driver.switchTo().window(switchTo);
    }

    // ── Scroll ────────────────────────────────────────────────
    public static void scrollToBottom(WebDriver driver) {
        ((JavascriptExecutor) driver)
            .executeScript("window.scrollTo(0, document.body.scrollHeight)");
    }

    public static void scrollToTop(WebDriver driver) {
        ((JavascriptExecutor) driver).executeScript("window.scrollTo(0, 0)");
    }

    public static void scrollToElement(WebDriver driver, WebElement el) {
        ((JavascriptExecutor) driver)
            .executeScript("arguments[0].scrollIntoView(true)", el);
    }

    // ── Page State ────────────────────────────────────────────
    public static boolean isPageLoaded(WebDriver driver) {
        return ((JavascriptExecutor) driver)
            .executeScript("return document.readyState")
            .equals("complete");
    }

    public static boolean urlContains(WebDriver driver, String text) {
        return driver.getCurrentUrl().contains(text);
    }

    public static boolean titleEquals(WebDriver driver, String expected) {
        return driver.getTitle().equals(expected);
    }

    // ── Sleep (temporary — remove after Day 20) ───────────────
    public static void pause(int ms) {
        try { Thread.sleep(ms); }
        catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
}

Full Script — Multi-Tab Automation

JavaMultiTabTest.java
package com.qaautomation.tests;

import com.qaautomation.utils.BrowserUtils;
import com.qaautomation.utils.DriverFactory;
import org.openqa.selenium.*;

public class MultiTabTest {

    public static void main(String[] args) {

        WebDriver driver = DriverFactory.getDriver("chrome");

        try {
            // ── Tab 1: OrangeHRM ─────────────────────────────────
            driver.get("https://opensource-demo.orangehrmlive.com");
            String mainTab = BrowserUtils.getMainTab(driver);
            System.out.println("[Tab1] Title: " + driver.getTitle());

            // ── Open Tab 2: Selenium website ─────────────────────
            driver.switchTo().newWindow(WindowType.TAB);
            driver.get("https://www.selenium.dev");
            String tab2 = driver.getWindowHandle();
            System.out.println("[Tab2] Title: " + driver.getTitle());

            // ── Open Tab 3: DemoQA ────────────────────────────────
            driver.switchTo().newWindow(WindowType.TAB);
            driver.get("https://demoqa.com");
            System.out.println("[Tab3] Title: " + driver.getTitle());

            // ── Print all open tabs ───────────────────────────────
            System.out.println("\nAll open tabs: " + driver.getWindowHandles().size());

            // ── Switch back to Tab 1 ─────────────────────────────
            driver.switchTo().window(mainTab);
            System.out.println("\nBack to Tab1: " + driver.getTitle());

            // ── Close Tab 2 ───────────────────────────────────────
            driver.switchTo().window(tab2);
            System.out.println("Closing Tab2: " + driver.getTitle());
            BrowserUtils.closeCurrentAndSwitch(driver, mainTab);

            System.out.println("Tabs remaining: " + driver.getWindowHandles().size());
            System.out.println("Current tab: " + driver.getTitle());

            // ── Scroll on current page ────────────────────────────
            BrowserUtils.scrollToBottom(driver);
            BrowserUtils.pause(500);
            BrowserUtils.scrollToTop(driver);
            System.out.println("Scrolled down and back up");

            // ── Page state check ──────────────────────────────────
            System.out.println("Page loaded: " + BrowserUtils.isPageLoaded(driver));
            System.out.println("URL check  : " + BrowserUtils.urlContains(driver, "orangehrm"));

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("Browser closed ✓");
        }
    }
}

Common Mistakes

❌ Not saving mainTab handle

Opening a new tab without saving the original handle means you can't get back. Always String mainTab = driver.getWindowHandle() before opening new tabs.

❌ No switchTo after driver.close()

After closing any tab with close(), driver is in limbo. Immediately call driver.switchTo().window(someHandle) or next command throws NoSuchWindowException.

❌ WindowType import missing

WindowType.TAB is in org.openqa.selenium.WindowType. If IntelliJ can't resolve it, make sure selenium-java version is 4.x (not 3.x) in pom.xml.

❌ JS executeScript returns Object, not String

executeScript returns Object. Always cast: (String) js.executeScript(...) or call .toString() on the result. Null check if element might not exist.

❌ getWindowHandles() Set has no order

getWindowHandles() returns a Set which has no guaranteed order. To get "newest" tab, convert to List and take last element, or loop and find the one that isn't mainTab.

❌ scrollIntoView before element loads

Calling scrollToElement() before the element exists throws NoSuchElementException. Always find the element successfully before scrolling to it.
