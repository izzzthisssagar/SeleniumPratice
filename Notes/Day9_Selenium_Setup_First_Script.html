What is Selenium WebDriver?

⏰ Hour 1 — Setup (60 mins)

Selenium WebDriver is a browser automation library. It lets you write Java code that directly controls a browser — clicks buttons, fills forms, reads text, takes screenshots — exactly like a real user would, but programmatically and at speed.

ComponentWhat It IsYour Role
Selenium WebDriverThe Java library — API you write code againstAdd as Maven dependency, write tests
ChromeDriverExecutable that bridges your Java code to Chrome browserWebDriverManager handles this automatically
Chrome BrowserThe actual browser being automatedMust be installed. Keep it updated.
WebDriverManagerLibrary that auto-downloads correct driver versionCall setup() once — done
MavenBuild tool that downloads all dependencies from internetAdd dependencies to pom.xml
02

Selenium Architecture — How It Works

// Selenium WebDriver Architecture
📌
WebDriverManager eliminates the manual driver headache

Without WebDriverManager, you'd have to manually download chromedriver.exe, match it to your exact Chrome version, and update it every time Chrome updates. WebDriverManager does all that in ONE line: WebDriverManager.chromedriver().setup(). Always use it.

What is Maven?

Maven is a build and dependency management tool. You declare what libraries you need in a file called pom.xml, and Maven downloads them from the internet automatically. No more manually downloading JAR files.

XMLHow Maven works — concept
<!-- pom.xml — you declare: "I need Selenium 4.x" -->
<!-- Maven automatically downloads: -->
<!--   selenium-java-4.x.jar -->
<!--   all its internal dependencies (byte-buddy, guava, etc.) -->
<!--   puts them in your project classpath -->
<!-- You just write code — no manual downloads ever -->
Maven ConceptPlain English
pom.xmlProject config file — lists all dependencies, project info, build settings
dependencyA library you want to use (Selenium, TestNG, etc.)
groupIdThe organization that made the library (like a domain name)
artifactIdThe specific library name
versionWhich version to download
Maven RepositoryCentral online store where Maven downloads libraries from (mvnrepository.com)

Step-by-Step Setup — Maven Project in IntelliJ

  • 1
    Open IntelliJ IDEA → File → New → Project In the left panel, select Maven. Make sure your JDK 17 is selected in the SDK dropdown. Click Next.
  • 2
    Set Project Name and GroupId Name: SeleniumAutomation  |  GroupId: com.qaautomation  |  ArtifactId: SeleniumAutomation. Click Finish.
  • 3
    Wait for Maven to initialize IntelliJ downloads the Maven wrapper. Watch the progress bar at the bottom. Takes 30–60 seconds on first run.
  • 4
    Open pom.xml (it's in the project root) You'll see the basic pom.xml with your groupId and artifactId. This is where you add dependencies in Section 5.
  • 5
    Create your first test class Right-click src/main/java → New → Java Class → name it FirstSeleniumTest. Or create a package first: com.qaautomation.tests.
✅
Enable Auto-Import in IntelliJ

Go to File → Settings → Build, Execution, Deployment → Build Tools → Maven → Importing → check "Import Maven projects automatically". This way whenever you edit pom.xml, IntelliJ immediately downloads new dependencies without you clicking anything.

Your First Selenium Script — Line by Line

⏰ Hour 2 — First Script (60 mins)
JavaFirstSeleniumTest.java — Every line explained
package com.qaautomation.tests;

// Import Selenium's WebDriver interface
import org.openqa.selenium.WebDriver;

// Import Chrome-specific driver
import org.openqa.selenium.chrome.ChromeDriver;

// Import WebDriverManager — auto-manages driver binary
import io.github.bonigarcia.wdm.WebDriverManager;

public class FirstSeleniumTest {

    public static void main(String[] args) {

        // STEP 1: Set up ChromeDriver automatically
        // Checks your Chrome version, downloads matching chromedriver.exe
        // Stores in ~/.cache/selenium — only downloads once
        WebDriverManager.chromedriver().setup();

        // STEP 2: Create WebDriver object (opens Chrome browser)
        // WebDriver = interface (left side)
        // ChromeDriver = implementation (right side) — Day 5 interface pattern!
        WebDriver driver = new ChromeDriver();

        try {

            // STEP 3: Navigate to a URL
            driver.get("https://opensource-demo.orangehrmlive.com");

            // STEP 4: Get current page title
            String title = driver.getTitle();
            System.out.println("Page title   : " + title);

            // STEP 5: Get current URL
            String currentUrl = driver.getCurrentUrl();
            System.out.println("Current URL  : " + currentUrl);

            // STEP 6: Get page source (full HTML)
            String source = driver.getPageSource();
            System.out.println("Page source length: " + source.length() + " chars");

            // STEP 7: Maximize browser window
            driver.manage().window().maximize();
            System.out.println("Window maximized");

            // STEP 8: Navigate to another page
            driver.navigate().to("https://www.google.com");
            System.out.println("Navigated to : " + driver.getTitle());

            // STEP 9: Go back
            driver.navigate().back();
            System.out.println("Back to      : " + driver.getTitle());

            // STEP 10: Go forward
            driver.navigate().forward();
            System.out.println("Forward to   : " + driver.getTitle());

            // STEP 11: Refresh page
            driver.navigate().refresh();
            System.out.println("Page refreshed");

        } finally {
            // STEP 12: ALWAYS close browser in finally
            // driver.close() — closes current tab only
            // driver.quit()  — closes ALL tabs + kills driver process
            driver.quit();
            System.out.println("Browser closed ✓");
        }
    }
}

Browser Navigation Methods

JavaNavigation.java
// driver.get() vs driver.navigate().to() — both load a URL
// driver.get() waits for page to fully load
// driver.navigate().to() same behavior, but navigate() gives more options
driver.get("https://site.com");             // preferred for direct URL load
driver.navigate().to("https://site.com"); // same result

// Browser history navigation
driver.navigate().back();      // browser back button
driver.navigate().forward(); // browser forward button
driver.navigate().refresh(); // F5 / page reload

// Window management
driver.manage().window().maximize();                 // full screen
driver.manage().window().minimize();                 // minimize
driver.manage().window().fullscreen();               // true fullscreen (F11)
driver.manage().window().setSize(new Dimension(1280, 800)); // specific size

// Get all open window handles (tabs)
Set<String> handles = driver.getWindowHandles();
System.out.println("Open tabs: " + handles.size());

// Current tab handle
String mainTab = driver.getWindowHandle();

// Implicit wait — wait up to X seconds for elements to appear (Day 20)
import java.time.Duration;
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));

ChromeOptions — Headless & Other Settings

ChromeOptions lets you configure Chrome behavior before launching. Headless mode is critical for CI/CD pipelines (no GUI needed on a server).

JavaChromeOptions.java
import org.openqa.selenium.chrome.ChromeOptions;

ChromeOptions options = new ChromeOptions();

// Headless mode — Chrome runs without opening a visible window
// Required for running tests in CI/CD (GitHub Actions)
options.addArguments("--headless=new");

// Disable browser automation detection banner
options.addArguments("--disable-blink-features=AutomationControlled");

// Set window size for headless (important! default is tiny)
options.addArguments("--window-size=1920,1080");

// Disable notifications popup
options.addArguments("--disable-notifications");

// Disable infobars ("Chrome is being controlled by automated software")
options.addArguments("--disable-infobars");

// Launch Chrome with these options
WebDriverManager.chromedriver().setup();
WebDriver driver = new ChromeDriver(options);

// Verify it worked even in headless
driver.get("https://www.google.com");
System.out.println("Title: " + driver.getTitle()); // Google — no browser opened!
driver.quit();

Running on Firefox & Edge

JavaCrossBrowserSetup.java
import org.openqa.selenium.firefox.FirefoxDriver;
import org.openqa.selenium.edge.EdgeDriver;

// Firefox — must have Firefox installed
WebDriverManager.firefoxdriver().setup();
WebDriver firefox = new FirefoxDriver();
firefox.get("https://www.google.com");
System.out.println("Firefox: " + firefox.getTitle());
firefox.quit();

// Edge — must have Edge installed (Windows 10/11 has it by default)
WebDriverManager.edgedriver().setup();
WebDriver edge = new EdgeDriver();
edge.get("https://www.google.com");
System.out.println("Edge: " + edge.getTitle());
edge.quit();

// Cross-browser method using String parameter
public static WebDriver getDriver(String browser) {
    switch (browser.toLowerCase()) {
        case "chrome":
            WebDriverManager.chromedriver().setup();
            return new ChromeDriver();
        case "firefox":
            WebDriverManager.firefoxdriver().setup();
            return new FirefoxDriver();
        case "edge":
            WebDriverManager.edgedriver().setup();
            return new EdgeDriver();
        default:
            throw new IllegalArgumentException("Unsupported: " + browser);
    }
}

Troubleshooting Setup Issues

Practice Task + Expected Output

JavaDay9Practice.java
package com.qaautomation.tests;

import io.github.bonigarcia.wdm.WebDriverManager;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.chrome.ChromeOptions;
import java.time.Duration;

public class Day9Practice {

    public static void main(String[] args) {

        // Setup
        WebDriverManager.chromedriver().setup();
        ChromeOptions options = new ChromeOptions();
        options.addArguments("--disable-notifications");

        WebDriver driver = new ChromeDriver(options);
        driver.manage().window().maximize();
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(5));

        try {
            // ── Task 1: Visit 3 sites, print titles ──────────────
            System.out.println("====== TASK 1: Site Titles ======");
            String[] urls = {
                "https://opensource-demo.orangehrmlive.com",
                "https://www.selenium.dev",
                "https://demoqa.com"
            };
            for (String url : urls) {
                driver.get(url);
                System.out.printf("  URL: %-45s Title: %s%n",
                    url, driver.getTitle());
            }

            // ── Task 2: Navigation test ───────────────────────────
            System.out.println("\n====== TASK 2: Browser Navigation ======");
            driver.get("https://opensource-demo.orangehrmlive.com");
            System.out.println("  Start : " + driver.getTitle());

            driver.navigate().to("https://www.google.com");
            System.out.println("  Google: " + driver.getTitle());

            driver.navigate().back();
            System.out.println("  Back  : " + driver.getTitle());

            driver.navigate().forward();
            System.out.println("  Fwd   : " + driver.getTitle());

            driver.navigate().refresh();
            System.out.println("  Refresh: page reloaded");

            // ── Task 3: URL validation ────────────────────────────
            System.out.println("\n====== TASK 3: URL Check ======");
            driver.get("https://opensource-demo.orangehrmlive.com");
            String url = driver.getCurrentUrl();
            boolean isLogin = url.contains("login") || url.contains("auth");
            System.out.println("  URL         : " + url);
            System.out.println("  Is login page: " + isLogin);
            System.out.println("  Title        : " + driver.getTitle());
            System.out.println("  Source len   : " + driver.getPageSource().length());

        } catch (Exception e) {
            System.out.println("Test failed: " + e.getMessage());
            e.printStackTrace();
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ Forgetting driver.quit()

Chrome processes pile up in Task Manager if you don't quit. Always in finally. A lingering ChromeDriver process from 10 test runs = 10 Chrome instances eating RAM.

❌ driver.close() vs driver.quit()

close() only closes the current tab — driver is still running. quit() kills everything. Use quit() in finally unless you specifically need to close just one tab.

❌ Not calling WebDriverManager.setup()

Creating new ChromeDriver() without WebDriverManager.chromedriver().setup() first crashes with "driver not found." Always setup before creating driver.

❌ Missing Maven reload after pom.xml edit

Adding a dependency to pom.xml but not reloading Maven means IntelliJ still can't find the classes. Right-click pom.xml → Maven → Reload Project.

❌ driver.get() without https://

driver.get("orangehrm.com") treats it as a search query on Chrome, not a URL. Always include https:// prefix.

❌ Running without maximize

Default Chrome window size may be small — some elements are hidden or overlap. Always call driver.manage().window().maximize() right after creating the driver.
