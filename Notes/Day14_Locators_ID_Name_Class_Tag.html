What is a Locator?

⏰ Hour 1 — Simple Locators (60 mins)

A locator is how you tell Selenium which element on the page you want to interact with. It's the translation between "click the Login button" and the actual HTML element on screen. Getting locators right is the single most important skill in Selenium — a bad locator is the #1 cause of flaky tests.

03

Locator Priority — Which to Use First

1. By.id ⭐
Always check for id first. IDs are meant to be unique. Fastest lookup. Most stable across page changes.
2. By.name ⭐
Use for form fields (input, select, textarea). Very common and stable. Second choice after id.
3. By.cssSelector ★
Powerful and fast. Use when no id/name available. Covered fully on Day 16.
4. By.xpath ★
Most flexible — handles complex cases. Slightly slower. Full coverage Day 15.
5. By.className ★
OK if class is unique. Problem: classes often repeat across many elements.
6. By.tagName ⚠
Use only with findElements() to get all elements of a type. Useless for findElement().
✅
The Locator Decision Tree

When writing a locator: 1) Has id? → Use id. 2) Has name? → Use name. 3) Has unique class? → Use className or CSS. 4) Nothing clean? → Build XPath. Never use absolute XPath (auto-generated from DevTools) — they break with any HTML change.

04

By.id — Most Reliable Locator

The id attribute is supposed to be unique on the entire page (HTML spec). If an element has an id, use it — it's the fastest and most stable locator.

HTMLExample HTML
<input id="txtUsername" type="text" name="username" placeholder="Username">
<button id="btnLogin" type="submit">Login</button>
<div id="errorMsg" class="error-text">Invalid credentials</div>
JavaById.java
// Basic usage
WebElement userField  = driver.findElement(By.id("txtUsername"));
WebElement loginBtn   = driver.findElement(By.id("btnLogin"));
WebElement errorMsg   = driver.findElement(By.id("errorMsg"));

// Interact
userField.sendKeys("Admin");
loginBtn.click();
System.out.println(errorMsg.getText());

// Safe check — does element with this id exist?
boolean exists = !driver.findElements(By.id("errorMsg")).isEmpty();
System.out.println("Error shown: " + exists);

// WHEN IDs CHANGE: some frameworks generate dynamic IDs like:
// id="input-1638291234" — number changes each page load
// AVOID these. Use name or CSS instead.
⚡
Watch out for dynamic IDs

IDs like id="username-12345" where the number changes every page load are useless as locators. If the id contains a number that changes, use By.name or By.cssSelector instead. Always test your locator by refreshing the page and seeing if it still works.

05

By.name — Best for Form Fields

The name attribute is commonly used on form elements (input, select, textarea, radio buttons). It's the second most reliable locator after id.

HTMLForm HTML
<form>
  <input type="text"     name="username"  placeholder="Username">
  <input type="password" name="password"  placeholder="Password">
  <select name="country">
    <option value="np">Nepal</option>
    <option value="in">India</option>
  </select>
  <input type="radio" name="gender" value="male">   Male
  <input type="radio" name="gender" value="female"> Female
</form>
JavaByName.java
// Single element by name
WebElement usernameField = driver.findElement(By.name("username"));
WebElement passwordField = driver.findElement(By.name("password"));

usernameField.sendKeys("Admin");
passwordField.sendKeys("admin123");

// Multiple elements with same name (radio buttons)
List<WebElement> genderOptions = driver.findElements(By.name("gender"));
System.out.println("Gender options: " + genderOptions.size()); // 2

// Click radio button with specific value
for (WebElement option : genderOptions) {
    if (option.getAttribute("value").equals("male")) {
        option.click();
        break;
    }
}

// Verify field content
String typedValue = usernameField.getAttribute("value");
System.out.println("Field contains: " + typedValue); // Admin
06

By.className — Single Class Only

Finds elements by CSS class name. Critical rule: By.className only works with a single class name. If an element has multiple classes, pick one. Use By.cssSelector (Day 16) for multiple classes.

HTMLClass HTML
<input class="oxd-input oxd-input--active" name="username">
<button class="oxd-button oxd-button--medium oxd-button--main">Login</button>
<p class="error-message">Invalid credentials</p>
JavaByClassName.java
// Single class — works fine
WebElement error = driver.findElement(By.className("error-message"));
System.out.println(error.getText());

// Multiple classes — use ONLY ONE of them
// <input class="oxd-input oxd-input--active">
WebElement input = driver.findElement(By.className("oxd-input")); // ✓
// By.className("oxd-input oxd-input--active") ← ERROR: spaces not allowed!
// Use By.cssSelector(".oxd-input.oxd-input--active") for multiple classes (Day 16)

// Get ALL elements with a class — useful for lists
List<WebElement> allInputs = driver.findElements(By.className("oxd-input"));
System.out.println("Input count: " + allInputs.size());

for (WebElement el : allInputs) {
    System.out.println("  Tag: " + el.getTagName()
        + "  Name: " + el.getAttribute("name")
        + "  Displayed: " + el.isDisplayed());
}

// Check if error class present (test assertion)
boolean hasError = !driver.findElements(By.className("error-message")).isEmpty();
System.out.println("Error shown: " + hasError);
🚨
By.className with space = InvalidSelectorException

By.className("oxd-input oxd-input--active") throws InvalidSelectorException because the space makes Selenium think it's two separate class names. Always use only ONE class name. For multiple classes, use CSS selector: By.cssSelector(".oxd-input.oxd-input--active")

07

By.tagName — For All Elements of a Type

By.tagName finds elements by their HTML tag name. Almost always used with findElements() (plural) to get a collection of all elements of that type. Rarely useful with findElement() since there are usually many of the same tag.

JavaByTagName.java
// Get ALL links on page
List<WebElement> allLinks = driver.findElements(By.tagName("a"));
System.out.println("Total links: " + allLinks.size());
for (WebElement link : allLinks) {
    String text = link.getText();
    String href = link.getAttribute("href");
    if (!text.isEmpty()) {
        System.out.println("  Link: " + text + " → " + href);
    }
}

// Get ALL input fields on a form
List<WebElement> inputs = driver.findElements(By.tagName("input"));
System.out.println("Input fields: " + inputs.size());
for (WebElement input : inputs) {
    System.out.println("  type=" + input.getAttribute("type")
        + "  name=" + input.getAttribute("name"));
}

// Get ALL table rows
List<WebElement> rows = driver.findElements(By.tagName("tr"));
System.out.println("Table rows: " + rows.size());

// Get page's h1
WebElement heading = driver.findElement(By.tagName("h1")); // OK if only one h1
System.out.println("Page heading: " + heading.getText());
08

By.linkText & By.partialLinkText

Only works on <a> anchor elements. Matches by the visible text of the link.

HTMLLink HTML
<a href="/forgot-password">Forgot your password?</a>
<a href="/help">Need help? Click here</a>
<a href="/privacy">Privacy Policy</a>
JavaByLinkText.java
// By.linkText — exact full text match (case sensitive)
WebElement forgotLink = driver.findElement(By.linkText("Forgot your password?"));
forgotLink.click();

// By.partialLinkText — substring match
WebElement helpLink = driver.findElement(By.partialLinkText("Need help"));
helpLink.click();

// Get ALL links and filter by text
List<WebElement> links = driver.findElements(By.tagName("a"));
for (WebElement link : links) {
    if (link.getText().contains("Policy")) {
        System.out.println("Found: " + link.getText() + " → " + link.getAttribute("href"));
    }
}

// Limitations:
// - Only works on <a> tags (not buttons, divs, spans)
// - linkText is case-sensitive and whitespace-sensitive
// - Text changes = locator breaks (fragile for i18n apps)

Testing Locators in Browser Console

Before writing Java, always test your locator in the browser console (F12 → Console tab). This saves time — verify it works in 10 seconds before writing code.

JavaScriptBrowser Console — Test locators here (F12 → Console)
// Test By.id equivalent
document.getElementById("txtUsername")
// Returns: <input id="txtUsername" ...> or null

// Test By.name equivalent
document.querySelector("[name='username']")
// Returns: the element or null

// Test By.className equivalent
document.getElementsByClassName("oxd-input")
// Returns: HTMLCollection of all matches

// Test CSS selector (works for By.cssSelector too)
// $$ is DevTools shortcut for document.querySelectorAll
$$(".oxd-input")           // all elements with class oxd-input
$$("input[name='username']") // input with name="username"
$$("button[type='submit']")  // submit button

// Test XPath (Day 15)
// $x is DevTools shortcut for XPath
$x("//input[@name='username']")
$x("//button[text()='Login']")

// Check how many results your locator finds
$$(".oxd-input").length   // if more than 1, locator is not unique enough
✅
Golden Rule: Locator must return exactly 1 result for findElement()

In the browser console, run your selector. If it returns more than 1 element, your locator is not specific enough — findElement() will grab the first one arbitrarily. Make it more specific until $$(selector).length === 1. For findElements(), multiple results are expected and fine.

JavaBestPractice — Store locators as constants
// BAD — locator strings scattered everywhere
driver.findElement(By.name("username")).sendKeys("Admin");
driver.findElement(By.name("username")).clear();  // repeated string!

// GOOD — constants at top of class (pre-POM pattern)
private static final By USERNAME_FIELD  = By.name("username");
private static final By PASSWORD_FIELD  = By.name("password");
private static final By LOGIN_BUTTON    = By.cssSelector("button[type='submit']");
private static final By ERROR_MSG       = By.cssSelector(".oxd-alert-content");
private static final By USER_DROPDOWN  = By.cssSelector(".oxd-userdropdown-name");

// Usage — clean, maintainable, change in one place
driver.findElement(USERNAME_FIELD).sendKeys("Admin");
driver.findElement(PASSWORD_FIELD).sendKeys("admin123");
driver.findElement(LOGIN_BUTTON).click();

Practice Task + Expected Output

JavaDay14Practice.java
package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import java.util.List;

public class Day14Practice {

    // Locators as constants — best practice
    static final By USERNAME  = By.name("username");
    static final By PASSWORD  = By.name("password");
    static final By LOGIN_BTN = By.cssSelector("button[type='submit']");
    static final By ERROR     = By.cssSelector(".oxd-alert-content");
    static final By USER_NAME = By.cssSelector(".oxd-userdropdown-name");

    public static void main(String[] args) throws InterruptedException {

        WebDriver driver = DriverFactory.getDriver("chrome");

        try {
            driver.get(ConfigReader.getBaseUrl());

            // Task 1: By.name — login fields
            System.out.println("====== TASK 1: By.name ======");
            WebElement u = driver.findElement(USERNAME);
            WebElement p = driver.findElement(PASSWORD);
            System.out.println("  Username displayed: " + u.isDisplayed());
            System.out.println("  Password enabled  : " + p.isEnabled());
            System.out.println("  Username tag      : " + u.getTagName());
            System.out.println("  Password type     : " + p.getAttribute("type"));

            // Task 2: By.tagName — all inputs on page
            System.out.println("\n====== TASK 2: By.tagName ======");
            List<WebElement> inputs = driver.findElements(By.tagName("input"));
            System.out.println("  Total input fields: " + inputs.size());
            for (WebElement inp : inputs) {
                System.out.println("  type=" + inp.getAttribute("type")
                    + "  name=" + inp.getAttribute("name"));
            }

            // Task 3: By.linkText
            System.out.println("\n====== TASK 3: By.linkText ======");
            List<WebElement> links = driver.findElements(By.tagName("a"));
            System.out.println("  Total links: " + links.size());
            for (WebElement link : links) {
                String txt = link.getText();
                if (!txt.isEmpty())
                    System.out.println("  Link: '" + txt + "'");
            }

            // Task 4: Login + verify with locators
            System.out.println("\n====== TASK 4: Login Flow ======");
            u.sendKeys(ConfigReader.getUsername());
            p.sendKeys(ConfigReader.getPassword());
            driver.findElement(LOGIN_BTN).click();
            Thread.sleep(2000);
            boolean passed = driver.getCurrentUrl().contains("dashboard");
            String who = driver.findElement(USER_NAME).getText();
            System.out.println("  Dashboard reached: " + passed);
            System.out.println("  Logged in as    : " + who);
            System.out.println(passed ? "  ✓ PASS" : "  ✗ FAIL");

            // Task 5: Invalid login — check error
            System.out.println("\n====== TASK 5: Invalid Login ======");
            driver.get(ConfigReader.getBaseUrl());
            driver.findElement(USERNAME).sendKeys("wronguser");
            driver.findElement(PASSWORD).sendKeys("wrongpass");
            driver.findElement(LOGIN_BTN).click();
            Thread.sleep(1500);
            boolean errorShown = !driver.findElements(ERROR).isEmpty();
            System.out.println("  Error shown  : " + errorShown);
            if (errorShown)
                System.out.println("  Error message: " + driver.findElement(ERROR).getText());
            System.out.println(errorShown ? "  ✓ PASS" : "  ✗ FAIL");

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ By.className with spaces

By.className("class1 class2") throws InvalidSelectorException. Use only ONE class name. For multiple: By.cssSelector(".class1.class2")

❌ Using dynamic IDs

IDs like id="input_1712345678" change on every page load. Using them as locators creates tests that fail randomly. Always check if the ID is stable.

❌ By.tagName for findElement()

findElement(By.tagName("input")) returns the FIRST input on the page — which may not be what you want. Use with findElements() or add more specificity.

❌ linkText case sensitivity

By.linkText("forgot your password?") fails if actual link text is "Forgot your password?" (capital F). linkText is case-sensitive AND whitespace-sensitive.

❌ Not testing locator before coding

Writing Java with a locator that doesn't work, then debugging for 30 minutes. Always test in browser console first. Saves massive time.

❌ Locator returns multiple elements

findElement() with a non-unique locator grabs the first match — could be a hidden element or the wrong one. Verify your locator returns exactly 1 result in console.
