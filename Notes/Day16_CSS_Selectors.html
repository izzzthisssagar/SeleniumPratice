What is a CSS Selector?

⏰ Hour 1 — CSS Selector Fundamentals (60 mins)

A CSS selector is a pattern that matches HTML elements — the same syntax used by stylesheets to apply styling. Selenium uses it to locate elements too. CSS selectors are faster than XPath (natively parsed by the browser) and more readable for class and attribute-based locators.

📌
CSS vs XPath — Pick the right tool

CSS: class-based, attribute-based, descendant, child — fast and readable.
XPath: text-based (text()), parent traversal, complex relational — more powerful.
Learn both. A senior QA switches between them naturally based on the element.

Basic Selectors — tag, class, id

CSS + JavaBasicSelectors.java
// ── Tag selector ──────────────────────────────────────────────
By.cssSelector("input")          // all input elements
By.cssSelector("button")        // all buttons
By.cssSelector("h1")            // all h1 headings

// ── Class selector — dot prefix ───────────────────────────────
By.cssSelector(".oxd-input")    // any element with class oxd-input
By.cssSelector(".error-message")// any element with class error-message
By.cssSelector(".oxd-button")   // any element with class oxd-button

// ── ID selector — hash prefix ─────────────────────────────────
By.cssSelector("#loginBtn")     // element with id="loginBtn"
By.cssSelector("#username")    // element with id="username"

// ── Tag + Class (more specific) ───────────────────────────────
By.cssSelector("input.oxd-input")    // input with class oxd-input
By.cssSelector("button.oxd-button")  // button with class oxd-button
By.cssSelector("div.login-card")     // div with class login-card

// ── Tag + ID ──────────────────────────────────────────────────
By.cssSelector("input#txtUsername")  // input with id="txtUsername"

// Practical examples:
WebElement user = driver.findElement(By.cssSelector("input.oxd-input"));
user.sendKeys("Admin");
driver.findElement(By.cssSelector("button.oxd-button")).click();

Attribute Selectors

CSS + JavaAttributeSelectors.java
// ── [attribute='value'] — exact match ────────────────────────
By.cssSelector("input[name='username']")       // name equals "username"
By.cssSelector("input[type='password']")       // type equals "password"
By.cssSelector("button[type='submit']")        // submit button
By.cssSelector("a[href='/logout']")            // link to /logout
By.cssSelector("input[placeholder='Username']")  // input with placeholder

// ── [attribute] — attribute exists (any value) ───────────────
By.cssSelector("input[disabled]")    // any disabled input
By.cssSelector("input[required]")    // any required input
By.cssSelector("input[readonly]")    // any readonly input
By.cssSelector("img[alt]")          // images that have alt text

// ── Tag + attribute combination ───────────────────────────────
By.cssSelector("input[type='text'][name='username']")  // both conditions

// Practical examples from OrangeHRM:
By.cssSelector("input[name='username']")
By.cssSelector("input[name='password']")
By.cssSelector("button[type='submit']")

Attribute Value Matching — ^=, $=, *=

CSS offers partial attribute matching — crucial for dynamic attributes and partially known values.

OperatorMeaningExampleMatches
[attr^='val']Starts with[id^='input-']id="input-1234", id="input-abc"
[attr$='val']Ends with[class$='--active']class="oxd-input--active"
[attr*='val']Contains[class*='alert']class="oxd-alert-content"
CSS + JavaPartialMatch.java
// ^= starts with
By.cssSelector("input[id^='txt']")          // id starts with 'txt'
By.cssSelector("div[class^='oxd']")          // class starts with 'oxd'
By.cssSelector("a[href^='/dashboard']")       // href starts with '/dashboard'

// $= ends with
By.cssSelector("input[class$='--active']")    // class ends with '--active'
By.cssSelector("img[src$='.png']")           // png images
By.cssSelector("a[href$='.pdf']")            // PDF links

// *= contains (most flexible)
By.cssSelector("div[class*='alert']")         // class contains 'alert'
By.cssSelector("input[class*='input']")       // class contains 'input'
By.cssSelector("a[href*='orangehrm']")        // href contains 'orangehrm'
By.cssSelector("[class*='userdropdown']")     // any element with this in class

// Combined
By.cssSelector("input[type='text'][class*='oxd']")  // type=text AND class has 'oxd'

Combinators — descendant, child, sibling

CombinatorSymbolMeaningExample
DescendantspaceAny descendant (child, grandchild...)form input
Child>Direct child onlydiv > input
Adjacent sibling+Immediately following siblinglabel + input
General sibling~Any following siblinglabel ~ input
CSS + JavaCombinators.java
// ── Descendant (space) — most common ──────────────────────────
By.cssSelector("form input")                  // any input anywhere inside form
By.cssSelector(".login-form input")           // input inside element with class
By.cssSelector("div.card input[type='text']") // text input inside card div

// ── Child (>) — direct children only ─────────────────────────
By.cssSelector("form > div")                  // divs that are DIRECT children of form
By.cssSelector("ul > li")                    // li that are direct children of ul

// ── Adjacent sibling (+) ─────────────────────────────────────
// Finds input that comes IMMEDIATELY after a label
By.cssSelector("label + input")               // input right after label
By.cssSelector("h3 + p")                     // p immediately after h3

// ── General sibling (~) ───────────────────────────────────────
By.cssSelector("label ~ input")               // any input after label (same parent)

// Real OrangeHRM examples:
By.cssSelector(".oxd-form input[name='username']")
By.cssSelector(".login-card > div > button")
By.cssSelector(".oxd-table-body .oxd-table-row")  // all data rows in table

Multiple Classes

CSS handles multiple classes elegantly — just chain them with dots. This is where CSS beats XPath's verbose contains(@class,'a') and contains(@class,'b').

CSS + JavaMultipleClasses.java
// HTML: <input class="oxd-input oxd-input--active">

// Single class — matches if element HAS this class (among others)
By.cssSelector(".oxd-input")                      // any element with oxd-input

// Multiple classes — element must have ALL of them
By.cssSelector(".oxd-input.oxd-input--active")     // has BOTH classes
By.cssSelector(".oxd-button.oxd-button--main")     // main button variant
By.cssSelector(".oxd-button.oxd-button--medium")   // medium size button

// Tag + multiple classes
By.cssSelector("input.oxd-input.oxd-input--active") // input with both classes
By.cssSelector("button.oxd-button.oxd-button--main") // main button

// vs XPath equivalent (much more verbose):
// "//input[contains(@class,'oxd-input') and contains(@class,'oxd-input--active')]"
// CSS wins for multi-class selection

Pseudo-selectors — :first-child, :last-child, :nth-child

CSS + JavaPseudoSelectors.java
// ── :first-child ─────────────────────────────────────────────
By.cssSelector("li:first-child")          // first li in its parent
By.cssSelector("tr:first-child")          // first row in table
By.cssSelector(".menu > a:first-child")   // first link in menu

// ── :last-child ──────────────────────────────────────────────
By.cssSelector("li:last-child")           // last list item
By.cssSelector("tr:last-child")           // last table row

// ── :nth-child(n) ─────────────────────────────────────────────
By.cssSelector("tr:nth-child(2)")         // 2nd row (first data row)
By.cssSelector("tr:nth-child(3)")         // 3rd row
By.cssSelector("tr:nth-child(odd)")       // odd rows
By.cssSelector("tr:nth-child(even)")      // even rows
By.cssSelector("li:nth-child(2n+1)")      // odd items (formula)

// ── :nth-of-type(n) — among same-type siblings ───────────────
By.cssSelector("input:nth-of-type(1)")    // first input in parent
By.cssSelector("input:nth-of-type(2)")    // second input (password field)

// Table cell targeting
By.cssSelector("tbody tr:nth-child(1) td:nth-child(2)") // row1, col2

// All data rows (skip header)
List<WebElement> rows = driver.findElements(
    By.cssSelector("tbody tr"));
System.out.println("Data rows: " + rows.size());

Pseudo-classes — :not(), :enabled, :disabled, :checked

CSS + JavaPseudoClasses.java
// ── :not() — exclude elements ────────────────────────────────
By.cssSelector("input:not([type='hidden'])")  // non-hidden inputs
By.cssSelector("button:not([disabled])")      // enabled buttons only
By.cssSelector(".item:not(.selected)")        // unselected items

// ── :enabled / :disabled ─────────────────────────────────────
By.cssSelector("input:enabled")    // all enabled inputs
By.cssSelector("input:disabled")   // all disabled inputs
By.cssSelector("button:enabled")   // clickable buttons

// ── :checked ─────────────────────────────────────────────────
By.cssSelector("input:checked")        // checked checkboxes/radios
By.cssSelector("input[type='checkbox']:checked") // only checked checkboxes
By.cssSelector("input[type='radio']:checked")    // selected radio button

// ── :focus ───────────────────────────────────────────────────
By.cssSelector("input:focus")     // currently focused input

// ── :empty — element with no children ────────────────────────
By.cssSelector("div:empty")       // empty div (no content)

// Combined practical examples
By.cssSelector("input[type='text']:enabled:not([readonly])")  // editable text inputs
List<WebElement> checks = driver.findElements(
    By.cssSelector("input[type='checkbox']:checked"));
System.out.println("Checked boxes: " + checks.size());

Complete Locator Strategy Reference

After Days 14, 15, 16 — here is the complete reference for all locator strategies. Bookmark this as your daily reference.

JavaCompleteLocatorReference.java
// ═══════════════════════════════════════════════════════════
// TIER 1 — Use first (most specific, most stable)
// ═══════════════════════════════════════════════════════════
By.id("loginBtn")                              // id attribute
By.name("username")                            // name attribute (form fields)

// ═══════════════════════════════════════════════════════════
// TIER 2 — Use when no id/name (CSS)
// ═══════════════════════════════════════════════════════════
By.cssSelector("button[type='submit']")         // attribute
By.cssSelector(".oxd-input")                   // class
By.cssSelector(".oxd-button.oxd-button--main")  // multiple classes
By.cssSelector("input[class*='oxd-input']")    // partial class
By.cssSelector("form input:nth-of-type(2)")    // nth element
By.cssSelector("label + input")               // sibling
By.cssSelector("input:not([disabled])")        // not disabled

// ═══════════════════════════════════════════════════════════
// TIER 3 — Use for text, parent nav, complex (XPath)
// ═══════════════════════════════════════════════════════════
By.xpath("//button[text()='Login']")           // text match
By.xpath("//a[contains(text(),'Forgot')]")     // partial text
By.xpath("//label[text()='User']/following-sibling::input") // sibling
By.xpath("//input/parent::div")               // parent nav
By.xpath("//tr[td[text()='John']]//button")   // row-based
By.xpath("(//input)[last()]")                 // positional

// ═══════════════════════════════════════════════════════════
// TIER 4 — Use for collections only
// ═══════════════════════════════════════════════════════════
By.tagName("input")     // all inputs (findElements)
By.tagName("a")         // all links (findElements)
By.tagName("tr")        // all rows (findElements)

// ═══════════════════════════════════════════════════════════
// AVOID — fragile
// ═══════════════════════════════════════════════════════════
// By.xpath("/html/body/div[3]/...")  ← absolute xpath - NEVER
// By.id("input-1638291234")         ← dynamic id - AVOID
// By.linkText("Submit")             ← text changes = breaks

Practice Task + Expected Output

JavaDay16Practice.java
package com.qaautomation.tests;

import com.qaautomation.utils.*;
import org.openqa.selenium.*;
import java.util.List;

public class Day16Practice {

    // CSS locators as constants
    static final By USERNAME  = By.cssSelector("input[name='username']");
    static final By PASSWORD  = By.cssSelector("input[name='password']");
    static final By LOGIN_BTN = By.cssSelector("button[type='submit']");
    static final By ERROR     = By.cssSelector(".oxd-alert-content");
    static final By USER_NAME = By.cssSelector(".oxd-userdropdown-name");
    static final By ALL_INPUTS= By.cssSelector("input:not([type='hidden'])");

    public static void main(String[] args) throws InterruptedException {
        WebDriver driver = DriverFactory.getDriver("chrome");
        try {
            driver.get(ConfigReader.getBaseUrl());

            // Task 1: Basic CSS selectors
            System.out.println("====== TASK 1: CSS Selectors ======");
            System.out.println("  Username visible: " + driver.findElement(USERNAME).isDisplayed());
            System.out.println("  Password type   : " + driver.findElement(PASSWORD).getAttribute("type"));
            System.out.println("  Button enabled  : " + driver.findElement(LOGIN_BTN).isEnabled());

            // Task 2: findElements with CSS
            System.out.println("\n====== TASK 2: findElements CSS ======");
            List<WebElement> inputs = driver.findElements(ALL_INPUTS);
            System.out.println("  Visible inputs: " + inputs.size());
            for (WebElement i : inputs)
                System.out.println("  → name=" + i.getAttribute("name") + " type=" + i.getAttribute("type"));

            // Task 3: Login with CSS locators
            System.out.println("\n====== TASK 3: Login ======");
            driver.findElement(USERNAME).sendKeys(ConfigReader.getUsername());
            driver.findElement(PASSWORD).sendKeys(ConfigReader.getPassword());
            driver.findElement(LOGIN_BTN).click();
            Thread.sleep(2000);
            boolean passed = driver.getCurrentUrl().contains("dashboard");
            System.out.println("  Logged in as: " + driver.findElement(USER_NAME).getText());
            System.out.println(passed ? "  ✓ PASS" : "  ✗ FAIL");

            // Task 4: attribute value matching operators
            System.out.println("\n====== TASK 4: Attribute Matching ======");
            driver.get(ConfigReader.getBaseUrl());
            boolean startsOxd = !driver.findElements(
                By.cssSelector("input[class*='oxd-input']")).isEmpty();
            boolean submitType = !driver.findElements(
                By.cssSelector("button[type='submit']")).isEmpty();
            boolean enInputs  = !driver.findElements(
                By.cssSelector("input:enabled")).isEmpty();
            System.out.println("  class*='oxd-input': " + startsOxd);
            System.out.println("  button[type=submit]: " + submitType);
            System.out.println("  input:enabled     : " + enInputs);

            // Task 5: nth-of-type
            System.out.println("\n====== TASK 5: nth-of-type ======");
            WebElement firstInput  = driver.findElement(By.cssSelector("input:nth-of-type(1)"));
            WebElement secondInput = driver.findElement(By.cssSelector("input:nth-of-type(2)"));
            System.out.println("  1st input name: " + firstInput.getAttribute("name"));
            System.out.println("  2nd input name: " + secondInput.getAttribute("name"));

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            driver.quit();
            System.out.println("\nBrowser closed ✓");
        }
    }
}

Common Mistakes

❌ Confusing . and # prefixes

.classname = class selector. #idname = id selector. [attr] = attribute selector. No prefix = tag name. Mix them up and nothing is found.

❌ CSS can't match by text

There is no CSS equivalent of XPath's text()='Login'. If you need to find an element by its visible text, you must use XPath. This is the key limitation of CSS selectors.

❌ CSS can't navigate to parent

CSS has no parent selector. div > input finds input INSIDE div — you can't go UP the tree. For parent navigation, use XPath //input/parent::div.

❌ Space vs > (descendant vs child)

div input finds any input inside div at any depth. div > input only finds direct children. The wrong one may match the wrong element.

❌ :nth-child vs :nth-of-type

input:nth-child(2) finds input that is the 2nd child of its parent. input:nth-of-type(2) finds the 2nd input within its parent. They differ when there are mixed element types.

❌ Testing selector returns 0

If $$(".myClass").length === 0 in console, the selector is wrong or element isn't on the page yet. Check spelling, check page load, check if it's in an iframe.
