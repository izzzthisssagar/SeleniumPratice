Why Methods & Arrays Matter in Selenium

By Phase 3, every single action in Selenium will be a method. Click a button? Method. Enter text? Method. Verify a title? Method. The Page Object Model (POM) — your final framework — is literally a collection of methods inside classes. Arrays power data-driven testing — one test, 50 login combinations, zero code repetition.

ConceptReal Selenium Usage
void methodclickLoginButton() — performs action, returns nothing
return methodgetPageTitle() — returns current page title as String
parametersenterUsername(String user) — types given text into field
static methodUtility helpers: takeScreenshot(), readConfig()
array / listAll findElements() results — returns list of web elements
2D arrayTest data: row = test case, columns = username/password/expected

04

void Methods — No Return Value

A void method performs an action and returns nothing. In Selenium, actions like clicking, typing, scrolling are all void methods — they do the thing and that's it.

JavaVoidMethods.java
public class VoidMethods {

    // void — does something, returns nothing
    public static void printWelcome() {
        System.out.println("==============================");
        System.out.println("   Welcome to OrangeHRM QA   ");
        System.out.println("==============================");
    }

    // void with parameters
    public static void printTestResult(String testName, boolean passed) {
        String status = passed ? "PASS" : "FAIL";
        System.out.println("[" + status + "] " + testName);
    }

    public static void main(String[] args) {
        printWelcome();
        printTestResult("Login with valid credentials", true);
        printTestResult("Login with wrong password",    false);
        printTestResult("Login with empty fields",       false);
    }
}
// ==============================
//    Welcome to OrangeHRM QA
// ==============================
// [PASS] Login with valid credentials
// [FAIL] Login with wrong password
// [FAIL] Login with empty fields
📌
void methods CAN use return; to exit early

You can write return; inside a void method to bail out early based on a condition. It just can't return a value. Useful when you want to skip execution if a precondition fails.

05

Return Methods — Sending Data Back

A return method computes something and sends it back to whoever called it. The caller can store it, print it, or pass it into another method.

// How return works — Data flows back to caller
JavaReturnMethods.java
public class ReturnMethods {

    // Returns String
    public static String getPageTitle() {
        return "OrangeHRM";
    }

    // Returns int
    public static int addNumbers(int a, int b) {
        return a + b;
    }

    // Returns boolean — perfect for test assertions
    public static boolean isValidScore(int score) {
        return score >= 0 && score <= 100;
    }

    // Early return — exit on invalid input
    public static String getGrade(int score) {
        if (score < 0 || score > 100) return "Invalid";  // early exit!
        if (score >= 90) return "A";
        if (score >= 80) return "B";
        if (score >= 70) return "C";
        return "F";
    }

    public static void main(String[] args) {
        String  title = getPageTitle();
        int     sum   = addNumbers(15, 27);
        boolean valid = isValidScore(85);
        String  grade = getGrade(73);

        System.out.println("Title : " + title);   // OrangeHRM
        System.out.println("Sum   : " + sum);     // 42
        System.out.println("Valid : " + valid);   // true
        System.out.println("Grade : " + grade);   // C

        // Use return value without storing
        System.out.println(getGrade(95));  // A
    }
}
🚨
Every non-void method MUST return in EVERY possible code path

If your method says it returns String but one branch of an if-else has no return, Java gives compile error: "missing return statement." All branches must return something.

06

Parameters vs Arguments

Parameter = variable in the method definition (what it expects). Argument = actual value you pass when calling (what you send). They're linked by position — first argument goes to first parameter.

JavaParams.java
//           parameter1    parameter2
//                ↓              ↓
public static void loginAs(String username, String password) {
    System.out.println("User: " + username + "  Pass: " + password);
}

public static void main(String[] args) {
    //       argument1    argument2
    //           ↓            ↓
    loginAs("Admin", "admin123");   // "Admin"→username, "admin123"→password
    loginAs("sagar", "test@123");
}

// IMPORTANT: Primitives passed BY VALUE (method gets a copy)
int x = 10;
modifyValue(x);
System.out.println(x); // still 10! method only changed its own copy

public static void modifyValue(int num) {
    num = 99;  // changes local copy only, NOT original x
}

Multiple Parameters

JavaMultiParams.java
public static String buildReport(String testName, boolean passed, int duration, String browser) {
    String status = passed ? "PASS" : "FAIL";
    return String.format("[%s] %s | %ds | %s", status, testName, duration, browser);

public static void main(String[] args) {

    System.out.println(buildReport("Logout Test", false, 1, "Firefox"));
}
// [PASS] Login Test  | 3s | Chrome
// [FAIL] Logout Test | 1s | Firefox

Method Overloading

Same method name, different parameter signatures. Java picks the correct version based on what arguments you pass. Used extensively in Selenium's By class and WebDriverWait.

JavaOverloading.java
// Three versions of "login" — Java picks the right one by argument types
public static void login(String user, String pass) {
    System.out.println("Login: " + user);
}
public static void login(String user, String pass, boolean remember) {
    System.out.println("Login: " + user + " remember=" + remember);
}
public static void login(int userId) {
    System.out.println("Login by ID: " + userId);
}

login("admin", "pass");           // version 1
login("admin", "pass", true);    // version 2
login(1042);                       // version 3

static vs Non-static Methods

TypeKeywordHow to CallWhen to Use
staticstaticDirectly or ClassName.method()Utility/helper methods. No object needed.
non-static(none)Create object first: obj.method()POM page classes. Each test gets its own instance.
JavaStaticVsInstance.java
public class LoginPage {

    // static — belongs to the CLASS, no object needed
    public static String getUrl() {
        return "https://opensource-demo.orangehrmlive.com";
    }

    // non-static — belongs to an OBJECT of LoginPage
    public void enterUsername(String user) {
        System.out.println("Typing: " + user);
    }
}

public static void main(String[] args) {
    // static — no object needed
    System.out.println(LoginPage.getUrl());

    // non-static — must create object first
    LoginPage page = new LoginPage();
    page.enterUsername("Admin");
}
📌
POM Connection — Day 34

Page classes (LoginPage, DashboardPage) use non-static methods — each test gets its own page instance. Utility classes (Config, DriverFactory) use static methods — called without creating objects. Both patterns appear in your final framework.

Variable Scope

Scope = where a variable can be accessed. A variable only exists inside the block it was declared in. Outside that block — it's gone.

JavaScope.java
public class Scope {

    // CLASS-LEVEL variable — accessible by ALL methods
    static String browser = "Chrome";

    public static void runTest() {
        // LOCAL variable — only inside runTest()
        String testName = "Login Test";

        if (true) {
            int attempts = 3;       // only inside this if block
            System.out.println(attempts);  // ✓ works here
        }
        // System.out.println(attempts); ← ERROR: out of scope

        System.out.println(testName);  // ✓ same method
        System.out.println(browser);   // ✓ class-level
    }

    public static void main(String[] args) {
        runTest();
        System.out.println(browser);   // ✓ class-level accessible
        // System.out.println(testName); ← ERROR: testName is in runTest only
    }
}

What is an Array?

⏰ Hour 2 — Arrays (60 mins)

An array is a fixed-size container that holds multiple values of the same type. Each slot has an index starting from 0 — never 1. Size is locked after creation — it cannot grow or shrink.

Accessing & Modifying Elements

JavaArrayAccess.java
String[] users = {"admin", "sagar", "guest"};

// Read by index
System.out.println(users[0]);                    // admin (first)
System.out.println(users[2]);                    // guest (last)
System.out.println(users[users.length - 1]);     // guest (safe last)

// Modify by index
users[1] = "sagar_qa";
System.out.println(users[1]);                    // sagar_qa

// Length: no parentheses for arrays!
System.out.println("Total: " + users.length);   // 3

// DANGER: index out of bounds = runtime crash
// System.out.println(users[5]);  ← ArrayIndexOutOfBoundsException!
// Last valid index = length - 1 = 2

Looping Through Arrays

JavaArrayLoops.java
String[] tests = {"LoginTest", "LogoutTest", "RegisterTest"};

// Regular for — use when you need the index
for (int i = 0; i < tests.length; i++) {
    System.out.println("Test #" + (i+1) + ": " + tests[i]);

// for-each — cleanest when you just need values

// Find maximum score in an array
int[] scores = {78, 95, 62, 88, 91};
int max = scores[0];
for (int s : scores) {
    if (s > max) max = s;

2D Arrays — Test Data Table

An array of arrays. Think of it as a table: rows = test cases, columns = fields. This is exactly how data-driven testing works — one test method, multiple data sets.

JavaTwoDArray.java
// 2D array: login test data
// columns: [0]=username  [1]=password  [2]=expected result
String[][] loginData = {
    {"Admin",  "admin123",  "Dashboard"},   // valid login
    {"Admin",  "wrongpass", "Invalid"},     // wrong password
    {"",       "",           "Required"}     // empty fields
};

// Access: [row][column]
System.out.println(loginData[0][0]);  // Admin
System.out.println(loginData[1][2]);  // Invalid

// Loop all rows
for (int row = 0; row < loginData.length; row++) {
    System.out.printf("Test %d: user=%-8s pass=%-10s expect=%s%n",
        row+1, loginData[row][0], loginData[row][1], loginData[row][2]);
}
// Test 1: user=Admin    pass=admin123   expect=Dashboard
// Test 2: user=Admin    pass=wrongpass  expect=Invalid
// Test 3: user=         pass=           expect=Required

Arrays Utility Methods

JavaArrayUtils.java
import java.util.Arrays;

int[] scores = {78, 95, 62, 88, 71};

// Sort ascending
Arrays.sort(scores);
System.out.println(Arrays.toString(scores));  // [62, 71, 78, 88, 95]

// Print array readable — NEVER use scores.toString() directly
System.out.println(Arrays.toString(scores));

// Copy
int[] copy = Arrays.copyOf(scores, scores.length);

// Fill all slots with same value
int[] zeros = new int[5];
Arrays.fill(zeros, 0);

// Manual sum + average
int total = 0;
for (int s : scores) total += s;
System.out.println("Sum: "     + total);
System.out.println("Average: " + (total / scores.length));

Methods + Arrays Together

JavaMethodsAndArrays.java
// Method that takes array, returns count
public static int countPassed(boolean[] results) {
    int count = 0;
    for (boolean r : results) if (r) count++;
    return count;
}

// Method that takes String array, returns joined string
public static String join(String[] items) {
    String result = "";
    for (int i = 0; i < items.length; i++) {
        result += items[i];
        if (i < items.length - 1) result += ", ";
    }
    return result;
}

// Method that creates and returns an array
public static int[] generateScores(int count) {
    int[] arr = new int[count];
    for (int i = 0; i < count; i++) arr[i] = (i+1) * 10;
    return arr;
}

boolean[] r = {true, false, true, true};
System.out.println("Passed: " + countPassed(r) + "/" + r.length);  // 3/4

String[] b = {"Chrome", "Firefox", "Edge"};
System.out.println(join(b));  // Chrome, Firefox, Edge

int[] gen = generateScores(5);
for (int s : gen) System.out.print(s + " ");  // 10 20 30 40 50

Practice Task + Expected Output

Type all of this from scratch. This combines everything from Days 1–3. This is the most complete code you've written so far.

JavaDay3Practice.java
import java.util.Arrays;

public class Day3Practice {

    public static void header(String title) {
        System.out.println("\n====== " + title + " ======");
    }

    public static String getGrade(int score) {
        if      (score >= 90) return "A";
        else if (score >= 80) return "B";
        else if (score >= 70) return "C";
        else if (score >= 50) return "D";
        else                   return "F";
    }

    public static int countPass(boolean[] res) {
        int c = 0;
        for (boolean r : res) if (r) c++;
        return c;
    }

    public static int maxScore(int[] arr) {
        int max = arr[0];
        for (int s : arr) if (s > max) max = s;
        return max;
    }

    public static void printReport(String[] names, boolean[] passed) {
        for (int i = 0; i < names.length; i++) {
            String s = passed[i] ? "PASS" : "FAIL";
            System.out.printf("  %-28s %s%n", names[i], s);
        }
    }

    public static void main(String[] args) {

        header("GRADE CHECKER");
        int[] scores = {95, 83, 72, 48, 60};
        for (int s : scores)
            System.out.println("  Score " + s + " → Grade: " + getGrade(s));
        System.out.println("  Highest: " + maxScore(scores));

        header("TEST SUITE REPORT");
        String[]  tests   = {"Login - valid creds", "Login - wrong pass",
                               "Logout", "Register", "Reset password"};
        boolean[] results = {true, false, true, true, false};
        printReport(tests, results);
        System.out.println("\n  Summary: " + countPass(results)
                           + "/" + results.length + " passed");

        header("DATA-DRIVEN LOGIN");
        String[][] data = {
            {"Admin", "admin123",  "Dashboard"},
            {"Admin", "wrong",     "Invalid credentials"},
            {"",      "",           "Username required"}
        };
        for (int i = 0; i < data.length; i++)
            System.out.printf("  Test %d | %-8s | %-10s | %s%n",
                i+1, data[i][0], data[i][1], data[i][2]);

        header("ARRAY OPERATIONS");
        int[] raw = {55, 22, 88, 11, 66};
        System.out.println("  Before: " + Arrays.toString(raw));
        Arrays.sort(raw);
        System.out.println("  After : " + Arrays.toString(raw));
        System.out.println("  Min: " + raw[0] + "  Max: " + raw[raw.length-1]);
    }
}

Common Mistakes

❌ Return type mismatch

Method says int but you return "hello". Types must match exactly or you get a compile error.

❌ Missing return path

Every branch of an if-else must return something in a non-void method. One missing return = compile error.

❌ ArrayIndexOutOfBounds

Accessing index that doesn't exist. Array of size 3 has indices 0,1,2. Index 3 crashes at runtime.

❌ .length() on arrays

arr.length() is wrong — that's for String. Arrays use arr.length (no parentheses).

❌ Non-static from static

Calling non-static method from main() without an object. Create the object first: new ClassName().

❌ Printing array directly

System.out.println(arr) prints a memory address like [I@6d06d69c. Always use Arrays.toString(arr).

❌ Arrays can't grow

new String[3] is forever 3. You can't add a 4th element. Need dynamic size? Use ArrayList (Day 6).

❌ Wrong argument order

login("pass", "user") when method expects (username, password) — Java passes by position silently.
