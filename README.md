# My Automation Testing Learning Journey 🚀

Welcome to my Automation Testing repository! This repository documents my journey of learning Java and Selenium WebDriver from scratch. It contains all my daily notes, practice code, and mini-projects.

## 📂 Repository Structure

The repository is logically divided into two main sections: `Notes` for theory and `LearningAutomation` for practical implementation.

### 1. `Notes` 📝
This folder contains detailed HTML notes from my daily learning sessions. I have documented everything from basic Java to advanced Selenium concepts.

**Core Java Concepts (Days 1 - 8)**
* `Day1_Java_Setup_Variables_DataTypes.html` - Setting up Java, understanding Variables and Data Types.
* `Day2_Conditions_Loops.html` - Control flow statements (If-else, Switch, For loops, While loops).
* `Day3_Methods_Arrays.html` - Functions, Methods, and Arrays in Java.
* `Day4_OOP_Classes_Objects.html` - Object-Oriented Programming: Classes and Objects.
* `Day5_Inheritance_Interfaces.html` - Deep dive into OOP: Inheritance and Interfaces.
* `Day6_Collections_List_HashMap.html` - Java Collections Framework (Lists, Sets, HashMaps).
* `Day7_Exception_Handling.html` - Handling exceptions effectively using try-catch blocks.
* `Day8_MiniProject_Calculator.html` - A mini-project implementing a Calculator to apply all learned Java concepts.

**Selenium WebDriver (Days 9 - 11)**
* `Day9_Selenium_Setup_First_Script.html` - Setting up Selenium in the project and writing the first script.
* `Day10_WebDriver_Interface_Browser_Drivers.html` - Understanding the WebDriver interface and how Browser Drivers work.
* `Day11_First_Full_Selenium_Script.html` - Writing a complete, end-to-end Selenium automation script.

### 2. `LearningAutomation` 💻
This is a Maven-based Java project where I write, test, and execute my Selenium automation scripts.

* **Project Build File:** `pom.xml` - Manages project dependencies (like Selenium HQ, TestNG, etc.).
* **Test Scripts (`src/test/java/`):**
  * `FirstTestCase.java` - My very first working Selenium script.
  * `FirstTry.java` - Initial experiments with browser automation.
  * `LocatorsDemo.java` - Learning basic web element locators (ID, Name, ClassName, TagName, LinkText).
  * `CssLocators.java` - Mastering CSS Selectors to find complex elements.
  * `XpathDemo.java` - Using XPath for advanced web element identification.
  * `GetMethods.java` - Using WebDriver methods to extract data from the browser (`getTitle()`, `getCurrentUrl()`, `getText()`).
  * `ConditionalMethods.java` - Using conditional commands to check element states (`isDisplayed()`, `isEnabled()`, `isSelected()`).
